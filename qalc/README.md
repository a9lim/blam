# qALC executable reference and proofs

This directory is blam's accepted Python/Lean reference surface for qALC.
Architecture Gates 1 and 2 are closed; the next implementation step is the
Rust pillar under `src/`.

The authoritative entry points are:

- `GATE1.md` and `gate1_check.py` — the composed machine, finite-admission
  boundary, and Gate-1 battery;
- `GATE2.md` and `gate2_check.py` — the native-CNOT compiler theorem and
  Gate-2 battery;
- `kernel.py`, `wf.py`, `certify.py`, and `rri_direct.py` — the accepted v1.43
  kernel and admission surface;
- `readback.py`, `readback_certify.py`, and `semantics.py` — composed readback,
  conservative fallback, and semantic objects;
- `gate2_cnot_shadow.py`, `gate2_compiler.py`, `gate2_admission.py`, and
  `gate2_semantics.py` — the accepted Gate-2 extension. The `shadow` filename
  is retained as a source pin;
- `QalcComposedMachine.lean`, `Gate2PhysicalCompiler.lean`, the
  `Gate2Contextual*.lean` chain, `Gate2TerminalGarbage.lean`, and
  `Gate2CleanCompilation.lean` — the universal physical proof path; and
- `QalcConcreteCertificate.md` and `QalcConcreteBuild.py` — concrete Gate-1
  reachable-recall replay and rebuild entry point.

Run the authoritative batteries from the repository root:

```bash
python qalc/gate1_check.py
python qalc/gate2_check.py
```

The path-scoped `qALC` workflow runs that complete battery whenever this
directory changes.

The machine register is
[`docs/quantum-algebraic/kernel.md`](../docs/quantum-algebraic/kernel.md);
there is no second current register here. Generated `.lean` sources are
checked-in proof evidence
and are regenerated byte-identically by the batteries. `lean-toolchain` pins
the standalone proof surface to Lean 4.33.0. Generated `.olean` files and
`__pycache__/` are ignored, disposable build products.

Only current machine/compiler sources, proof records, generated evidence, and
the Gate-1 final log live here. Rejected routes and audit chronology belong in
[`docs/ledger/2026-08.md`](../docs/ledger/2026-08.md), external audit records,
and git history.
