# Lower bounds for whole-stream and self-application readers

This is Codex's handwritten proof record. It concerns the reader `s H T` in
the ambient frame `[s,j,c,p,x]`, with `j,c,p,x` independent rigid variables.
The handler may use every ambient variable and arbitrary beta redexes.
The two operands considered here are `T=s` and `T=s s`.

The argument excludes every handler of at most 34 bits for `T=s`, and
at most 30 bits for `T=s s`, that satisfies both reader laws. Thus either
reader costs at least 43 bits. Together with the standard-skip theorem in
`handler-bound.md`, none of the operands `s`, `s s`, or `s s s` can improve
the 165 while its surrounding code and this interface stay fixed.
The proof is handwritten and independently reviewed, not a Lean
formalization. It does not establish global 165-bit optimality.

Write

```
K = λa b.a,                   F = λa b.b,
cons b r = λh.h b r,
P₀ = cons K N,                Pᵢ₊₁ = cons F Pᵢ,
I = λa.a,                     Q = K N.
```

Here `R,N` are fresh rigid variables. The zero-stream law, with
`Z=cons K R`, and the variable-stream law, with `m≥1`, are

```
H[Z/s] K R T[Z/s]       =β R j,
H[Pₘ/s] F Pₘ₋₁ T[Pₘ/s] =β c Pₘ₋₁ N.
```

The substitution notation is suppressed below when the stream is clear.

For `T=s`, the final argument is `Pₘ`; for `T=s s`, it reduces to `Q`.
Both are beta-normal abstractions, distinct from the rigid `N`.
Correctness on all variable streams alone forces **at least two explicit
lambdas in H**, and **at least three when H is beta-normal**. The
zero-stream law is not needed for these floors.

A reader improvement requires `|H|≤34` with `T=s`, or `|H|≤30`
with `T=s s`. The lambda floors alone do not exclude those budgets;
the compression and shape arguments below complete both exclusions.

## The application-only data algebra

Consider application-only expressions generated by the `Pᵢ`, `F`,
and rigid variables. Their normal forms are either one of the functional
data values

```
Pᵢ, F, I, Q
```

or a rigid-headed neutral. Arguments inside a neutral may contain normal
data, including a bare `K`; its rigid head prevents their extraction.
Every functional data value contains only `N` as a possible free variable,
and in particular contains no `c`.

The following application table proves closure. Write `tail₀=N`,
`tailᵢ₊₁=Pᵢ`, `bit₀=K`, and `bitᵢ₊₁=F`.

| Function and argument | Reduct |
|---|---|
| `F V` | `I` |
| `I V` | `V` |
| `Q V` | `N` |
| `Pᵢ F` | `tailᵢ` |
| `P₀ I` | `Q` |
| `Pᵢ₊₁ I` | `I` |
| `Pᵢ Q` | `N tailᵢ` |
| `P₀ P₀` | `Q` |
| `P₀ Pⱼ₊₁` | `I` |
| `Pᵢ₊₁ P₀` | `N Pᵢ` |
| `Pᵢ₊₁ Pⱼ₊₁` | `Pⱼ Pᵢ` |
| `Pᵢ (z A₁ … Aₖ)` | `z A₁ … Aₖ bitᵢ tailᵢ` |

Applying a neutral to another argument preserves its rigid head.
The recursive pair/pair row decreases the sum of its indices. More
generally all data abstractions are affine, so application-only expressions
over these data normalize. Induction on the applicative expression,
using this table, establishes the claimed normal-form grammar.

The exclusion of bare `K` from the functional values matters. For example,
`P₀ K → K`; that would invalidate the grammar if `K` were freely
available as a function. It is not an initial generator here. `P₀ I`
and `P₀ P₀` expose only `K N`, while a `K` delivered to a rigid
neutral remains trapped in that neutral's argument spine.

## No explicit lambda

If `H` has no lambda, substitute `s=Pₘ` and normalize it in this
algebra. A functional data result contains no `c`, so applying it to
`F,Pₘ₋₁,T` cannot produce head `c`. A rigid-headed result keeps
that head and receives three additional arguments. If its head is `c`,
it therefore has at least three arguments, whereas the required normal
form has exactly two. Other rigid heads also fail.

## One leading lambda

Suppose `H=λb.B` and `B` contains no lambdas. After applying the first
argument `F`, the body belongs to the same application-only algebra.
A functional data normal form again contains no `c`. A rigid normal
form with head `c` receives the two remaining arguments `Pₘ₋₁,T`.
Matching the required two-argument spine forces the body's normal form
to be exactly `c`, and then forces `T=βN`. This is false for both
cheap operands. Other rigid heads fail immediately.

## An arbitrarily placed single lambda

A syntactic beta redex in a one-lambda `H` consumes that unique lambda.
Contract it before substituting the stream. The reduct is application-only,
so the preceding zero-lambda obstruction applies. It remains to consider
beta-normal `H` whose unique lambda is not necessarily at the root.

Write that lambda as `D=λz.B`, where `B` is application-only. Replace
its single occurrence by a fresh opaque rigid marker `d`. The remaining
syntax is an application-only context `C[d]`. Let `a` be its number of
applications, counting the marker as one leaf. Choose a variable stream
`Pₘ` with `m>a+1`.

Normalize `C[d]` bottom-up while retaining `d` as rigid: first normalize
both children of an application, then use the data-algebra table. All
participating data binders are affine, so the marker is never copied.
The data-algebra grammar remains valid with `d` among the rigid heads.

There is also an index invariant:

> Every Scott cell obtained as a functional normal form of a subexpression
> is `Pₘ₋ₖ` with `0≤k≤` the number of applications in that subexpression.

Induct on the application tree. The source leaves have index `m`.
Identity forwards an already obtained value. The only table entry that
returns a new Scott value is `Pᵢ F→Pᵢ₋₁`, spending one application
for one decrement. Pair/pair interaction returns `I`, `Q`, or an
`N`-headed neutral; it never returns a Scott value. Other entries do
not introduce one.

In this normalization order, pair/pair reductions involve no marker.
Only a normalized functional Scott value applied to a `d`-headed
neutral can invoke the marker as a handler, so the index invariant
makes its index positive. In

```
Pᵢ (d A₁ … Aₖ) → d A₁ … Aₖ F Pᵢ₋₁,
```

the newly supplied bit is always `F`, never terminal `K`.
The first argument of a `d`-headed normal form therefore comes either
from an explicit application, whose operand normalized in the safe
algebra, or from such a positive-index Scott invocation. It is a safe
data value or a rigid neutral, never a bare functional `K`.
Cells or bare bits buried inside rigid neutrals cannot be extracted.
The marker's uniqueness ensures that none of its arguments contains
another copy of the marker.

There are now three possibilities for the normalized context:

* A functional data value has erased the marker. It contains no `c`
  and fails as in the zero-lambda case.
* A rigid neutral with head other than `d` remains rigid after replacing
  the marker by its lambda, even if that lambda occurs in an argument.
  Appending the three external arguments cannot produce the required
  two-argument `c` spine.
* The result is `d A₁ … Aₖ`. If `k=0`, restoring `D` gives the
  leading-lambda case: the first external argument is `F`, leaving
  `Pₘ₋₁,T`. If `k>0`, contract `D A₁` before appending any external
  arguments. Its body was application-only and its argument is safe;
  the remaining expression therefore belongs to the safe algebra,
  allowing rigid neutrals as additional opaque operands. Its functional
  data results still contain no `c`, and its rigid results retain all
  three external arguments. Neither can give the required output.

Thus a single lambda cannot meet the variable law for all lengths.
The long-prefix choice is essential to this proof: a callback activated
at a terminal `P₀` can receive bare `K`, after which it could construct
constant functions carrying arbitrary code. The index invariant excludes
that activation for the chosen stream rather than assuming it impossible.

## A beta-normal handler requires three source lambdas

For both cheap operands, the variable law alone excludes every
beta-normal handler with at most two source lambdas, at any size.
The preceding arguments handle zero or one lambda. Suppose now that
`H` is beta-normal with exactly two, and let `A` be its number of
source applications. Choose

```
m > A+2.
```

We first extend the one-marker argument slightly. Allow initial safe
functional data `Pₘ,Pₘ₋₁,F,I,Q`, and at most one source abstraction
`D=λv.W` with application-only body. Treat that unique abstraction as
an opaque marker during bottom-up normalization. With at most `A`
macro applications, every Scott cell obtained as a functional value
has index at least `m−1−A>0`: each predecessor extraction spends an
application, and the other table rows return no new Scott cell.
The marker therefore receives a safe first argument, never bare `K`.
Any syntactic redex headed by `D` can also be handled this way: its
argument has no source lambdas, so normalizing that argument first
makes it safe.

Suppose at least two external safe arguments are still pending,
with final argument `T`, where `T` is the original `Pₘ` or `Q`.
If the marker is activated internally, consuming its first safe
argument leaves an application-only expression in the safe algebra;
all pending external arguments remain. If it is returned bare, it
consumes the first pending argument and leaves at least the final
`T`. A functional safe result contains no `c`. A rigid-headed
result retains every still-pending argument. In particular a result
headed by `c` has last argument `T`, which is not beta-equivalent
to `N`. A marker trapped inside a rigid argument cannot change the
rigid head. These cases exclude the desired `c Pₘ₋₁ N`.

If `H` begins with a lambda, contract it against the first external
`F`. Substitution may copy `F`, but cannot copy the other source
lambda. The result has at most one source lambda, no more than `A`
macro applications when safe data are counted as atoms, and the two
pending arguments `Pₘ₋₁,T`. The extended one-marker argument applies.

It remains to consider application-headed `H`. Its source lambdas
occur inside argument positions, since `H` is beta-normal. Before
any such lambda is activated, replace each outermost lambda block
by a distinct opaque rigid marker. Application-only expressions over
`S=Pₘ` and rigid markers have functional normal forms only

```
S, Q.
```

Indeed, `S S→*Q`, `S Q→*N Pₘ₋₁`, and `Q V→N`;
application to a rigid neutral preserves a rigid head. A nontrivial
application subtree cannot return `S`. Thus, if any source lambda
is activated before the external arguments are supplied, a first
activation can be chosen at a literal source subterm `s D`, with
`D=λv.W`: the function subtree can return the calling cell only
when that subtree is literally `s`. If none is activated, the
result is safe data or a rigid neutral with all three external
arguments pending, and already fails.

Contract that literal subterm directly:

```
s (λv.W)  →*  W[F/v] Pₘ₋₁.
```

This consumes one source lambda without copying the other. It also
preserves the macro application count: the source application
`s D` is replaced by the application to `Pₘ₋₁`, and each
substituted `F` is a safe atom. All initial Scott values in the
residual expression have index `m` or `m−1`. The residual has at
most one source lambda and all three external arguments pending.
The extended one-marker argument again excludes the required output.

Therefore a beta-normal successful handler has at least three source
lambdas. The long-prefix witness is finite and explicit; this proof
does not assume that terminal callbacks are inaccessible on every
input.

The lambda count is sharp for each operand. These beta-normal handlers
use exactly three source lambdas and satisfy both corresponding reader
laws:

```
T=s s:   λb r t.b (r j) (c r (t t)),
T=s:     λb r t.b (r j) (c r (t t t)).
```

For the first, `t=K N` gives `t t→N`; for the second,
`t=Pₘ` gives `t t t→N`. The zero branch discards the continuation
branch in either case. Their measured encodings and rigid-law checks
are recorded in `STATUS.md` and the handler-bound fixture; sharpness
of the lambda count does not imply either handler meets its improving
size budget.

## Affine source lambdas and pending arguments

A source term is affine here when every source binder has at most one
bound occurrence. This condition is preserved by beta reduction: an
affine source binder cannot copy its argument, and every data binder
in the Scott cells, `F,I,Q` is also affine. In particular, a source
lambda moved inside another closure remains a single occurrence.

The preceding opaque-marker argument extends to any affine source
term. Suppose it contains `k` source lambdas and has `n≥k+1`
external data atoms still pending, chosen from `F,I,Q,Pₘ,Pₘ₋₁`,
with final argument `T` equal to the original `Pₘ` or `Q`.
For a sufficiently long variable prefix, it cannot yield
`c Pₘ₋₁ N`.

To make the long-prefix choice explicit, let `A` count the initial
macro applications, including those inside source lambda bodies,
with Scott values counted as atoms. Allow initial functional Scott
values `Pₘ,Pₘ₋₁`. It suffices to choose

```
m > 2^(k+1) (A+2).
```

Normalize the outer application context while treating its outermost
source-lambda blocks as distinct rigid markers. The data-algebra
table applies with these additional markers. In one normalization
phase the macro application count at most doubles. Normalize both
children first and inspect the table: a Scott value applied to a
marker-headed neutral is the largest case, replacing its one
application by two; the other rows add no more. Untouched lambda
bodies retain their original application nodes. A source
lambda contraction cannot increase the macro application count,
since its argument is used at most once. Across at most `k` source
activations, the successive counts are therefore bounded by
`A,2A,...,2^k A`.

A functional Scott predecessor spends an application, so the same
phase can increase a functional Scott index's offset from `m` by
at most its starting application count plus one. This also covers
the tail supplied when a Scott value invokes a marker. The displayed
choice of `m` exceeds the sum of all these bounds, including the
initial offset one. Pair/pair normalization may place shorter cells
inside an ordinary rigid neutral, but they remain trapped there and
cannot become functional values or standalone arguments of a source
callback. Consequently no source activation receives bare terminal
`K`. Its first argument is safe data, a marker-bearing expression,
or an ordinary rigid neutral. Restore every source block when
contracting one of them. The term may no longer be beta-normal;
the induction permits arbitrary affine terms and counts all
remaining source lambdas, including those moved into a closure.

Now induct on `k`. A functional data result has no `c`; an ordinary
rigid result retains the pending arguments and therefore retains final
`T≠βN`. If the result is a marked source lambda with an internal
argument, restore and contract it. At least one source lambda is
removed, none is copied, and all `n` external arguments remain.
Continue the induction on the resulting source term; a marker-bearing
argument need not become plain data when substituted. If instead the
result is a bare source lambda, supply the first pending external
argument. One source lambda and one pending argument are consumed,
leaving `n−1≥(k−1)+1`. These are all possibilities, proving the
claim.

In particular, a **beta-normal, application-headed affine handler
with at most three source lambdas fails the variable law**, for either
cheap operand. Before its first source activation, the application-only
context over `Pₘ` and rigid markers has functional values only
`Pₘ,Q`; a nontrivial context cannot return a bare marker. A source
lambda must therefore be activated internally before the external
arguments are supplied. This leaves at most two source lambdas and
all three pending arguments, so the lemma applies.

## Two source lambdas with one binary binder

This independently reviewed handwritten argument strengthens the
safe-data pending-argument obstruction. It uses the same fixed, fresh rigid N and safe
functional atoms F,I,Q,P_m,P_(m-1). Rigid neutrals may contain safe data,
source lambdas, and trapped terminal K; their arguments cannot be extracted
through a rigid head. A source lambda means an explicit code binder, not
a binder already inside a safe data atom.

Claim. Let G be any source term with at most two source lambdas, with at
most one binder having two bound occurrences and every other source binder
affine. No beta-normality assumption is made. For every sufficiently long
prefix, it cannot satisfy

    G F P_(m-1) P_m =beta c P_(m-1) N.

The initial source may contain arbitrary safe atoms and rigid markers.
Its source grammar and macro application count are fixed independently of
m. This is a restricted two-source-lambda theorem: two nonlinear binders,
or a binder with three occurrences, are not included.

### Controlled outermost activation and the long-prefix guard

Use the existing opaque-marker normalization strategy: replace each
outermost source-lambda block by one distinct rigid marker, normalize only
the exterior application context with the data-algebra table, and restore
and activate a source block only when its marked head is exposed. Source
lambda bodies remain opaque until their enclosing binder is activated.
In particular, a source binder below another source binder cannot be the
first activated source binder.

Until the first source activation, all reductions are affine data
reductions. No source block is copied, so there is at most one occurrence
of the possibly binary source lambda U. The other source lambda, if
present, is V and is affine. A functional data result has no c; an ordinary
rigid result retains all pending external arguments. These results already
fail. Otherwise the normalized exterior is a marked source lambda, bare
or supplied with one or more internal arguments.

As in the established index-ancestry proof, take m sufficiently large
that this and every subsequent source activation cannot receive bare
terminal K. This bounds offsets of exposed functional Scott values, not
the total number of beta steps: a pair/pair reduction may traverse the
whole prefix but returns I,Q or a rigid neutral, never an exposed terminal
callback. Each functional predecessor costs a macro application.

There are at most three source activations in the strategy below. An
opaque normalization phase at most doubles the macro application count;
the only potentially copying source contraction has multiplicity two and
at most doubles that count once. The other source contractions are affine.
Consequently all exposed Scott offsets have a finite bound independent of
m. For example, with initial macro application count A and initial Scott
offsets at most one, the generous choice

    m > 64 (A+2)

dominates the successive phase and tail-supply bounds. This allows the
already proved affine and one-source-lambda arguments to be reused after
the first activation, with their finite enlarged macro counts and offsets.

### First activation of the affine binder

Suppose V is activated first. Whether its argument is internal or the
first external F, its affine contraction cannot copy U. It leaves at most
one source lambda, U. There are respectively three or two external inputs
still pending, and their final input remains the original P_m.

The extended one-source-lambda obstruction already proved applies: its
body may use its bound variable more than once; an internal argument has
no other source lambda, and the long-prefix guard supplies only safe data
or a rigid neutral. If the remaining U is returned bare, it consumes one
pending safe argument and leaves the final P_m. Thus neither placement
can give the required target. If the first activation erased U entirely,
the base-data case applies instead.

This case also accounts for an affine V enclosing U. Activating V first
removes its binding scope before U can duplicate a former free V occurrence.
An affine substitution cannot increase the multiplicity of U's own bound
variable. The exterior argument cannot refer to that bound variable,
because its binding lambda lies inside V's body.

### First activation of the binary binder

Now suppose U is activated first. The opaque strategy guarantees that V
does not enclose U. This qualification matters: reducing U below an intact
V could otherwise copy a free occurrence bound by V and make V nonlinear.

If U has an internal argument, restore the actual source blocks in that
argument and contract U before supplying any of the three external inputs.
The argument cannot contain U itself: before this contraction there is
only one U occurrence, and it is the function being contracted. Any other
source lambda in the argument is V, which is affine. If V lies in the
argument, it is copied at most twice and each copy remains affine. If V
lies in U's body or in disjoint exterior syntax, it remains a single
affine source lambda. No enclosing V remains to have a bound occurrence
duplicated. The complete reduct is therefore affine, with at most two
source lambdas and all three external inputs still pending.

The established affine pending-argument lemma applies at k<=2,n=3.
Its source lambdas may contain c and may become constant closures; that
lemma counts these residual lambdas, including moved or copied closures,
and does not assume that a copied block is c-free. Safe data and ordinary
rigid neutrals are allowed in its exterior basis.

If U is returned bare, give it the first external argument F. Copying F
introduces no source lambda. At most the single affine V remains, with the
two inputs P_(m-1),P_m pending. The affine bound at k<=1,n=2 applies.

These alternatives exhaust the first exposed source block and prove the
claim. With no binary binder the ordinary affine bound already suffices.

### Application to normal application-headed three-lambda handlers

Let H be source-beta-normal and application-headed, with exactly three
source lambdas, at most one binary binder u, and every other source binder
affine. Its initial exterior basis contains only s and rigid markers;
multiple occurrences of s are allowed.
If no source lambda activates internally, safe data or a rigid head
receives all three external inputs and fails. Otherwise a first activation
can be chosen at a literal source subterm s D, for an outermost block D.
For a sufficiently long variable stream,

    S (lambda a.W) -> W[F/a] P_(m-1).

This consumes one source lambda and copies no source lambda. If a=u, the
two remaining source binders are affine, so the existing k<=2,n=3 bound
applies. If a is an affine binder, the residual has at most two
source lambdas: one binary u and one affine binder. Substitution of safe F
cannot increase u's own bound multiplicity. The theorem just proved then
excludes the residual, with all three external reader inputs still pending.

Thus every such three-lambda handler fails the variable law, regardless
of its application count or index budget. The all-affine case is already
covered by the existing restricted affine observation.

At A=5,L=3, mandatory j,c and at least one s consume three of the six
variable leaves. The remaining at most three leaves permit at most one
nonlinear binder. If its multiplicity is two, the new result applies,
including repeated s or other ambient leaves. The only higher-multiplicity
pattern is s,j,c,u,u,u. It has exactly one live binder and exactly one s,
so the independently reviewed ordered-input obstruction excludes it at
the improving 34-bit budget. Consequently every remaining normal
A=5,L=3,k=0 allocation is excluded. Larger source-lambda counts are not
covered by this argument.

## Three leading lambdas do not fit the whole-stream operand

For `T=s`, a beta-normal handler with exactly three source lambdas,
all leading, cannot satisfy both reader laws at size at most 34:

```
H = λb r t.B,             B application-only.
```

As above, higher ambient variables can be replaced by `j` without
increasing size. Both required rigid variables `j,c` must occur.

First suppose `b` is absent. This case fails regardless of size.
For the zero law, split the two origins of the remainder: substitute a
rigid `R₀` for the direct argument `r`, and substitute
`P=cons K R₁` for both `s,t`, with `R₁` independently rigid.
Application-only expressions over `P` and rigid variables normalize to
`P`, `K R₁`, or a rigid neutral. Identifying `R₀,R₁` with `R`
does not create beta redexes, so the zero law's normal form `R j`
must lift to either `R₀ j` or `R₁ j`.

The first alternative forces the literal source body `B=r j`. A
rigid function gains one argument when applied, a cell applied to a
neutral adds two arguments, and `K R₁` erases its argument. None
forwards a neutral unchanged. Thus a normal form headed by `R₀`
with the single argument `j` can only come from the direct application
`r j`; the same argument shows that bare `j` cannot be produced by a
nontrivial application-only expression. This body lacks the mandatory
`c`.

For the second alternative, compare the zero cell `P` to the variable
stream `Q=Pₘ(N)`, keeping `r=R₀` rigid for now. Pair functional values
`P` with `Q` and `K R₁` with `K N`; pair rigid neutrals by their
heads, mapping `R₁` to `N` and fixing `R₀,j,c`. The relevant
application rules are

```
P P       →* K R₁,           Q Q       →* K N,
P(K R₁)   →* R₁ R₁,         Q(K N)    →* N Pₘ₋₁(N).
```

Cells applied to rigid neutrals preserve their heads, and constant
functions discard their arguments. These cases prove the head relation
by structural induction. A zero result headed by `R₁` therefore becomes
rigidly `N`-headed on the variable stream. Finally substituting
`R₀=Pₘ₋₁(N)` cannot change that `N` head. It cannot yield the
required `c` head. This completes the `b`-absent obstruction.

Now suppose `b` occurs. Under the three leading lambdas, mandatory
occurrences of `b,j,c` contribute at least `2+4+5=11` to the
zero-based index sum. Four applications would therefore cost at least
`6+16+2+11=35` bits. Hence an improving handler has at most three
applications and four leaves.

Besides `b,j,c`, a fourth leaf `r,t`, or free `s` is necessary to
supply the rigid `R` in the zero result. With `r`, the zero body is
an application tree over one occurrence each of `K,R,j,c`. The
single `K` contraction must erase precisely `c` while preserving the
application `R j`. There are exactly three ways to place this erasure:

| Source body | Variable-stream result |
| --- | --- |
| `b r c j` | `c j` |
| `b (r j) c` | `c` |
| `r (b j c)` | `c bitₘ₋₁ tailₘ₋₁` |

The first two have the wrong argument count. For the last, already
`m=1` gives `c K N`, whose first argument is not `P₀(N)`.

With `t` or free `s` as the fourth leaf, the zero body has one
occurrence each of `P,K,j,c`. It cannot expose the payload `R`
as its head. A bare `K` callback gives `P K→K`; a partial callback
`K Z` gives `P(K Z)→Z R`, with `Z` headed by `j` or `c`;
and a rigid callback preserves its `j/c` head. The single `P`
cannot be copied, and there is no other source of an `R` head.
Thus these cases also fail.

This proves the stated 34-bit exclusion for exactly three leading
lambdas. It does not cover a fourth lambda in the body, nor does it
transfer the three displayed zero-compatible bodies to `T=s s`.

## Affine reductions preserve the 30-bit budget

The following compression results concern `T=s s` and require both laws:

```
H[cons K R] K R (K R) =β R j,
H[Pₘ(N)] F Pₘ₋₁(N) (K N) =β c Pₘ₋₁(N) N       for every m≥1.
```

All remainder variables are fresh and rigid, as are `j,c,p,x`. In
particular, both `j,c` occur freely in every successful handler and
every beta-equivalent reduct of it.

Suppose `|H|≤30` and a source redex `(λu.B) D` uses `u` exactly
once, at depth `d` inside `B`. Let `f` count the free-variable
occurrences of `D`, relative to `D` itself, and let `r` count the
other occurrences in `B` whose indices decrease when the binder `u`
is removed. The exact change in BLC size on contraction is

```
Δ = d(f−1) − 6 − r.
```

The contraction removes the variable encoding of size `d+2`, removes
four bits for the redex's application and lambda, shifts each of `D`'s
`f` free occurrences under `d` binders, and decreases the other `r`
indices by one. These are precisely the four contributions above.

Let `L,A,X` be the source lambda count, application count, and zero-based
index sum. The path to the bound occurrence gives `L≥d+1`; the
argument's leaves and the redex application give `A≥f`; and the bound
occurrence together with mandatory `j,c` gives `X≥d+3`. Consequently

```
30 ≥ |H| = 2L+4A+2+X ≥ 3d+4f+7.
```

For nonnegative integers satisfying this inequality,
`d(f−1)≤6`: for `f=0,1` the product is nonpositive or zero, and
for `f=2,3,4,5` its maxima are respectively `5,6,6,4`.
Larger `f` is impossible. Thus the contraction cannot increase size.
It also strictly decreases the number of source AST nodes. A vacuous
contraction strictly decreases both size and node count, since its
argument is erased and the remaining free indices only decrease.

Therefore, if a successful handler of size at most 30 exists, choose one
minimizing `(BLC size, AST node count)` lexicographically. It has no
affine beta redex. This is a reduction of the remaining search space,
not an exclusion of all compressed handlers: the smaller reduct may
still be a successful handler whose shape has not been priced.

## All-vacuous handlers fail the self-application operand

This obstruction has no size restriction. A source abstraction is
*vacuous* when its bound variable does not occur in its body. Suppose
every source abstraction in `H` is vacuous, while free occurrences of
`s,j,c,p,x` and arbitrary applications are allowed.

Compare the zero stream with the shortest variable stream:

```
P = cons K R,             U = cons K N,             Q = cons F U.
```

For expressions made from these source operations, pair their head
values at `s=P` and `s=Q` as follows:

* `P` corresponds to `Q`;
* constant functions correspond when their bodies have related head
  values;
* rigid-headed values correspond by their heads, mapping `R` to `N`
  and fixing `j,c,p,x`; their argument spines need not agree.

The relation is closed under application. Constants discard their
arguments, and rigid heads persist. The nontrivial cell cases are

```
P P →* K R,                       Q Q →* K N,
P (λ_.V) →* V R,                 Q (λ_.W) →* W U.
```

In the second line, related constant bodies again discard their
arguments, and related rigid bodies retain their heads. Related cell
bodies give `P R→R K R` and `Q U→*N U`, which have the related
rigid heads `R,N`. A cell applied to a rigid-headed value preserves
that value's head. These cases establish the relation by structural
induction. All source and data binders in these expressions are affine,
so the head evaluations terminate.

Now supply external arguments `K,R,K R` on the zero side. If the
head `P` is exposed with three, two, or one argument still pending,
the results are respectively

```
P K R (K R) →* R,
P R (K R)   →* R K R (K R),
P (K R)     →* R R.
```

None is `R j`. A rigid head exposed before the arguments are exhausted
retains the final functional argument `K R`, so it cannot become
`R j` either. The zero law therefore forces three successive
constant-function heads, discarding all three arguments, followed by a
rigid head `R`.

The related variable evaluation discards `F,U,K N` through three
corresponding constant functions and ends at rigid head `N`. This
contradicts its required head `c`. Thus an all-vacuous handler cannot
satisfy both laws for `T=s s`.

## Nonlinear redexes with at most four applications

Continue with the two `T=s s` laws above. In a minimum handler of
size at most 30, the affine-reduction lemma removes all affine source
redexes from consideration. A remaining source redex must bind its
variable at least twice. Such a redex is impossible when the handler
has at most four applications.

First record a consequence of having no free `s`. Any successful
handler with this restriction must use its first input non-vacuously.
Its zero behavior forces a leading lambda after head reduction. If
that first lambda were vacuous, write the handler as `λb.G`; the
zero law would give

```
G R (K R) →* R j.
```

Split the two sources of `R` into independently rigid `R₀,R₁`.
Identifying rigid variables creates no beta redexes, so the same
reduction lifts to either

```
G R₀ (K R₁) →* R₀ j,       or       G R₀ (K R₁) →* R₁ j.
```

Substituting `R₀:=Pₘ₋₁(N)` and `R₁:=N` gives respectively
a `j`-headed or an `N`-headed result, not the required `c` head.
This proves the first-input dependence.

It also excludes a no-`s` handler with at most one live source
binder, even if that binder has several occurrences and additional
vacuous binders are allowed. Its unique live binder must survive to
receive the first input `K`. After this substitution the only live
functional code is copied `K`; all other source lambdas are vacuous.
Their reductions merely select or erase subtrees and preserve the
left-to-right order of surviving rigid leaves. Every source `j`
precedes every `R` in the remaining external arguments `R,K R`,
whereas the required output `R j` reverses this order.

A handler with `A` applications has `A+1` variable leaves. At `A≤2`,
the two occurrences of a nonlinear binder and the mandatory `j,c`
already exceed that count. At `A=3`, these four leaves exhaust it;
after the nonlinear contraction every remaining source binder is
vacuous, contradicting the preceding obstruction.

At `A=4`, there is only one further leaf. If it is another occurrence
of the nonlinear binder or any ambient variable, all remaining source
binders are again vacuous after contraction. The only case left has
exactly the leaves

```
u, u, j, c, v,
```

where `v` is the sole occurrence bound by another live binder. In
particular, there is no free `s`.

Unless the argument of the nonlinear redex contains both that live
binder and its occurrence, contraction leaves at most one live binder.
It may now have repeated occurrences, but the no-`s` obstruction just
proved still applies. Otherwise call the copied argument `D`.
It contains one live binder, used once, and all its other binders are
vacuous. Its only possible free leaves are `j,c`. The absence of
affine source redexes makes `D` beta-normal.

If `D` has no rigid leaves, it is a pure projection: a chain of lambdas
ending in its one bound-variable leaf. After copying it, the remaining
source consists only of projections, vacuous lambdas, applications,
and rigid variables. Including the supplied `K`, all reductions still
select or erase subtrees and preserve surviving rigid-leaf order.
They cannot move an external `R` before a source `j`.

Suppose instead that `D` contains a rigid `j/c` leaf. A live binder
capable of receiving an external argument must lie in `D`'s leading
lambda chain. Otherwise a rigid head guards it permanently: for
example, the live binder in `λw.j (λv.v)` cannot become the
head function. Merely containing a rigid leaf is therefore not enough;
this accessibility qualification is essential.

For an accessible live binder `v`, all rigid leaves of `D` occur
in its body. After any remaining leading vacuous lambdas, that body's
beta-normal head is either rigid or has the form

```
v A₁ ... A_q,             q>0.
```

The case `q=0` would leave no place for a rigid leaf. Each `A_i`
contains only rigid `j/c` leaves and vacuous lambdas, since the sole
occurrence of `v` is already the head. Giving this live binder `K`
therefore produces either a rigid `j/c` head or selects `A₁`,
which can only expose a rigid `j/c` head or leave a lambda. It cannot
produce head `R`.

This property persists for every copied residual of the accessible
binder. Its preceding binders are vacuous, and there is no other free
bound-variable occurrence through which surrounding reductions could
insert a different body. First-input dependence requires the external
`K` to enter one of these live residuals, contradicting the zero law.
This completes the nonlinear-redex exclusion at `A≤4`.

Consequently a minimum successful handler of size at most 30, if one
exists, is beta-normal whenever it has at most four applications.

## Five-application nonlinear compression

The remaining compressed case has `A=5`. The two-lambda floor and
`X≥3`, together with `|H|≤30`, force

```
L=2,                    X≤4.
```

Choose a source redex. Contracting it must copy an argument containing
the other source lambda: otherwise its reduct has at most one explicit
lambda, contradicting the variable-law floor. Hence the whole handler
has the form

```
E[(λu.B) C[D]],          D=λv.W,
```

where `B,C,E,W` are application-only, `C` has one hole, and `B`
contains at least two occurrences of `u`. The argument `C[D]` is
beta-normal. Indeed, a redex headed by `D` there has a lambda-free
argument; contracting it leaves at most the outer source lambda,
again contradicting the floor. This argument also covers nonlinear
`D`; absence of affine redexes alone would not establish normality.

Neither source lambda lies inside the other. Every `u/v` leaf has
zero-based index zero, while each ambient leaf beneath either lambda
pays one extra index unit. Therefore

```
X = #j + 2#c + 3#p + 4#x + #(ambient leaves beneath a source lambda).
```

The mandatory `j,c` already cost three. Thus `p,x` are absent and
at most one ambient occurrence lies beneath either lambda. There are
only six variable leaves in total.

### No ambient leaf inside D

Here `W` is a pure application tree of `v`. The six-leaf budget
leaves only `D=I` or `D=Δ=λv.v v`. For `D=I`, substituting a
variable stream turns `C[D]`, then `B[C[D]/u]`, and finally the
whole surrounding context into expressions in the application-only
data algebra. This cannot satisfy the variable law.

For `D=Δ`, the leaves are exactly `u,u,v,v,j,c`, so there is no
free `s`. At most one of `j,c` occurs in `B`. If `C[D]` is not
the bare `D`, its beta-normal head is a rigid `j/c`, and the core
and surrounding context cannot expose a useful functional head.
Otherwise `B[D/u]` is either `D D`, or an application tree over
two copies of `D` and one rigid variable. The former has no head
normal form. In the latter, a `D` applied to a rigid-headed term
has a rigid head, while `D D` has no head normal form. These cases
exhaust the tree's possible head reductions. A rigid head retains
all three external arguments; a divergent head cannot yield the
required normal form. Neither succeeds.

### One ambient leaf inside D

Write that leaf as `a∈{s,j,c}`. Now `B` is a pure application tree
of `u`. If `v` occurs at most once, `D` is one of

```
C_a = λv.a,           R_a = λv.v a,           L_a = λv.a v.
```

These cases allow a uniform treatment of proper argument contexts
`C[D]`, including `s D`. Fix a variable stream `S=Pₘ(N)`, `m≥1`,
and adjoin the single value `D` to the base functional data
`Pᵢ,F,I,Q`. Rigid neutrals may contain `D` inside their arguments.
The enlarged grammar remains closed under application. Besides
`F D→I`, `I D→D`, and `Q D→N`, the useful rows are

| Added value | Its action | Scott invocation |
| --- | --- | --- |
| `C_a` | `C_a V→a` | `Pᵢ C_a→a tailᵢ` |
| `R_a` | `R_a V→V a` | `P₀ R_a→a`; `Pᵢ₊₁ R_a→Pᵢ` |
| `L_a` | `L_a V→a V` | `Pᵢ L_a→a bitᵢ tailᵢ` |

For rigid `a`, the indicated rigid heads persist. For `a=S`,
pair/pair applications return base data or neutrals, and the remaining
special cases are

```
R_S F→I,       R_S I→S,       R_S Q→N,       R_S R_S→Q,
L_S F→Pₘ₋₁,   L_S I→I,       L_S Q→N Pₘ₋₁, L_S L_S→Q,
P₀ L_S→I,                    Pᵢ₊₁ L_S→Pₘ₋₁ Pᵢ.
```

All source and data binders in these cases are affine, so bottom-up
normalization terminates. It follows that an arbitrary argument
context `C[D]` normalizes to base data, to `D` itself, or to a rigid
neutral. A base-data result stays in the base algebra through the pure
`u` tree; a rigid result stays rigid. It remains to check that a
nontrivial tree of bare copies of `D` does not leave `D` exposed.

For rigid `a`, every such tree is rigid-headed: `C_a C_a→a`,
`R_a R_a→a a`, and `L_a L_a→a L_a`, and further applications
preserve this property. For `R_S,L_S`, two copies give `Q` and
three or more give an `N`-headed neutral. For `C_S`, the leaf count
is essential: `k` copies in the body use `k+3` source leaves,
including `s,j,c`, so `k≤3`. The possible trees give

```
C_S C_S→S,
C_S(C_S C_S)→S,
(C_S C_S)C_S→S C_S→S Pₘ₋₁.
```

All are base data or neutrals. Four copies are not available; this
restriction cannot be dropped, since further applications can expose
`C_S` again.

If `v` occurs twice, the six leaves force `a` to be rigid and exclude
every free `s`. A proper `C[D]` is again rigid-headed. For the bare
argument, `B=u u`, and the possible bodies `W` are

```
v(v a),   v(a v),   a(v v),   (v v)a,   (v a)v,   (a v)v.
```

Their self-applications have rigid head `a`, except `(v v)a`,
whose self-application repeatedly returns to itself with one more
argument and has no head normal form. More occurrences of `v`
exceed the leaf budget. This completes the remaining cases.

In every affine added-value case the core reduces into the original
base data algebra before any external argument is supplied, and the
application-only surrounding context preserves that algebra. Functional
base results contain no `c`; rigid results retain three additional
arguments and cannot become the required two-argument `c` spine.
The exceptional nonlinear cases already fail by their head behavior.
Thus five-application nonlinear compression is also impossible.

Since `A≥6` would cost at least `2·2+4·6+2+3=33` bits,
these results prove that **if a successful `T=s s` handler of size
at most 30 exists, one of minimum size is beta-normal**. The
remaining sections exclude every possible shape of that normal
minimum.

## Normal handlers with at most three applications

A beta-normal minimum candidate for `T=s s` cannot have `A≤3`.
We already know `L≥3`. An `A`-application term has `A+1` variable
leaves, including mandatory occurrences of `j,c`. At `A≤2`, if
`s` occurs then all source binders are vacuous; if it does not, there
is at most one live source binder. Both cases were excluded above.

For `A=3`, the same obstructions leave exactly two leaf patterns:

```
j,c,u,v:  two distinct live bound variables, with no free s;
j,c,s,v:  one live bound variable, with one free s.
```

Each displayed leaf occurs once. Every source binder is therefore
affine. Let `k` count the leading lambdas of `H`; the zero law
forces `k≤3`, since a fourth unconsumed leading lambda cannot equal
`R j`. A rigid `j/c` body head is immediately impossible.

### No free s

First-input dependence forces the first leading binder `b` to be
one of the two live binders. A body headed by the second input `r`
would retain the final external `K R` unless `k=3`. At `k=3`,
mandatory leaves `b,r,j,c` have index sum at least `2+1+4+5=12`,
so their size is at least 32. A body headed by the third input `t`
gives the functional value `K N` or rigid head `N` on variable
streams. Thus the body head must be `b`.

The case `k=3` already costs at least 31: `b,j,c` contribute
`2+4+5=11` to the index sum, even allowing zero contribution from
the remaining leaf. It remains to consider `k=1,2` and a Boolean
head

```
b A₁ ... A_q.
```

For `q=1`, the variable branch `F A₁` erases the sole source of
`c`, so it cannot work. For `q=2`, `j` must lie in `A₁` and
`c` in `A₂`. There is only one remaining application and one
remaining bound-variable leaf. Thus one branch is a lambda chain
over its single rigid leaf. If it is the zero branch, that branch
cannot acquire head `R`. If it is the `c` branch, after receiving
the pending arguments its result is a lambda, bare `c`, or `c`
applied to a suffix of the pending arguments. Any nonempty suffix
ends in `K N`; none is `c Pₘ₋₁ N`.

For `q=3`, all three arguments are lambda chains over single
leaves. The zero branch must contain the live leaf, the variable
branch `c`, and the shared third argument `j`; any other allocation
makes the zero head rigidly `j/c` or loses one required rigid leaf.
The zero branch is a projection or a constant returning a leading
input. Its argument order is the `j`-bearing shared argument first,
then the still-pending external arguments, ending in `K R`.
Projections and constants select or erase this ordered list. They
cannot move the earlier `j` after a later `R` to form `R j`;
exposing a rigid `R` sooner retains the final `K R` instead.
Selecting the last external `R` through `K` can also erase that
final argument, but then yields bare `R`. This
excludes the no-`s` pattern.

### One free s and a bound body head

Suppose the body head is the unique live bound variable. A second-input
head again requires `k=3` to avoid retaining the final external
`K R`; its mandatory `r,s,j,c` then have index sum at least 13,
which costs at least 33. A third-input head again fails by its
variable-stream head `N`. Only the first-input head `b` remains.

If `k=2`, the four leaves `b,s,j,c` contribute at least ten to
the index sum. Since `L≥3`, an additional lambda lies beneath the
leading pair and increases at least one of those leaf indices. This
costs at least `6+12+2+11=31`. For `k=3` the bound is larger.
Hence only `k=1` needs consideration.

With two Boolean arguments, the zero branch must contain `s,j`
and the variable branch is a lambda chain over its single `c`.
That branch fails by the same final-argument obstruction. With three
arguments, all argument blocks are constant chains over `s,j,c`.
To obtain a zero result with head `R`, the selected first block must
return `P=cons K R`, and the shared third block must contain `j`.
The selected block receives, in order, that `j` block, then `R`,
then `K R`. Depending on how many arguments its constant chain
erases, exposing `P` gives a `j` head, `R K R (K R)`, `R R`,
or an unconsumed lambda. None is `R j`. One Boolean argument
again erases `c` on the variable branch.

### Free s as the body head

Write

```
H = λ^k.s A₁ ... A_q.
```

On the zero stream, the first argument receives `K,R`, followed
by `A₂,...,A_q` and the `3−k` pending external arguments. All
source lambdas except the binder of the single leaf `v` are
vacuous.

For `q=3`, each argument is a lambda chain over one leaf. The
first must contain `v`, and the other two contain `j,c`. Its
activation is therefore just projection or constant selection from
that argument list. If `k<3`, the final external `K R` again
prevents the result `R j`: once `R` is exposed it retains that
last argument, while selection of the last `K R` leaves a lambda; selecting the
last external `R` through `K` can instead yield bare `R`.
The one-leaf blocks cannot construct a constant wrapper around an
already formed `R j`. For `k=3`, at least one callback lambda is
needed. Thus `L≥4`, while `s,j,c` already contribute
`3+4+5=12` to the index sum, for size at least 34.

For `q=2`, one argument contains the sole remaining application.
If it is `A₂`, then `A₁` is a projection or constant chain over
`v`, while `A₂` contains `j,c` in a rigid application. The latter
can never produce bare `j`, so no selection gives `R j`.
Otherwise the only possible non-rigid head of `A₁` is `v`, and
its shape is a lambda chain over `v J`, where `J` is a constant
chain over one of `j,c`; `A₂` is a chain over the other.

If `J` contains `j`, the live variable must receive `R` and
`J` must be bare `j`. To avoid trailing arguments, `A₁` must
consume all `6−k` supplied arguments before exposing `v j`.
Hence `L≥6`, and the deeply bound `j` alone contributes seven
index units; together with mandatory `c`, the size is at least 35.
If `J` contains `c`, the only way to discard it while producing
`R` before the remaining `j` argument is to give `v` the value
`K R`. The `j` argument must be last, so `k=3`; `v` must be
the outer third input, and two callback lambdas consume `K,R`.
Then `L≥5`, with `c` beneath five lambdas and `j` beneath three,
again exceeding 30.

For `q=1`, both remaining applications lie inside the first callback.
Its head must be `v`. A single argument containing the rigid
application of `j,c` cannot yield bare `j`: beta-normality rules
out a vacuous lambda in function position that could erase the other
rigid leaf. With two separate
arguments, only the body `v C j`, where `C` contains `c`, can
produce `R j`, and only when `v=K R`. This value either arrives
as the last pending external argument or is the outer third input
after consuming the Scott `K,R`. In either case at least five
source lambdas have been consumed, with both `j,c` beneath them.
Thus `L≥5`, `X≥6+7=13`, and the size is at least 37.

These cases exhaust the three-application normal shapes. Five or
more applications would cost at least `2·3+4·5+2+3=31` bits,
using the three-lambda floor and mandatory `j,c`. Every possible
30-bit improvement therefore has exactly four applications.

For these remaining candidates, let `k` again count the leading
lambdas. The size identity and mandatory rigid leaves give

```
2L+X≤12,             X≥2k+3,             hence L+k≤4.
```

Together with `L≥3`, this leaves only `L=3,k=0`, `L=4,k=0`,
and `L=3,k=1`. A nonleading normal candidate must have free `s`
as its body head; every other available head is rigid. Among its
five leaves, `s,j,c` are mandatory, leaving zero, one, or two
bound occurrences. Zero was excluded by the all-vacuous argument.
The next two sections handle one and two, and the final section
handles the single leading lambda.

## One bound leaf in a nonleading four-application handler

Consider a beta-normal, application-headed handler with `A=4`
and exactly one bound-variable leaf `v`. Its other four leaves
include `s,j,c` and one further ambient variable. Every source
binder is affine. The size budget gives either `L=3,X≤6` or
`L=4,X≤4`. The affine pending-argument lemma already excludes
the three-lambda case.

For `L=4`, mandatory `j,c` account for at least three index
units, so at most one further unit is available. A source lambda
not above the unique bound leaf must enclose an ambient leaf and
therefore spend at least one such unit. At least three lambdas
must consequently lie above `v`.

If all four lie above `v` and no ambient leaf lies below them,
they form one closed four-argument projection. The live variable
is its last or penultimate binder, since its index is at most one.
A first activation by a Scott cell consumes two source lambdas
before the external arguments arrive. At most two remain, so the
affine pending-argument lemma excludes the variable law.

Every other possibility contains the closed final projection

```
D = λa b v.v
```

and one additional vacuous lambda. Indeed, the single available
index unit is spent by an ambient leaf below that additional lambda;
the live variable must then have index zero. The extra lambda may
be separate, as `λu.a`, or may surround an application `a D`.
Beta-normality excludes `D a` inside that scope. These are the
only ways to distribute the single ambient leaf and the three-lambda
projection without paying a second index unit.

If `D` is activated internally before the extra vacuous lambda,
its first activation is a direct Scott invocation and consumes two
source lambdas. If it is activated after that extra lambda, even
one contraction of `D` makes two internal source activations in
total. Either case leaves at most two source lambdas with all three
external arguments pending, and the affine lemma applies.

It remains to consider reductions with no internal activation of
`D`. A source lambda reaching the head of the original normal,
application-headed term must first be activated internally. Thus
any useful source activation in this case consumes the unique
vacuous lambda. Normalize the resulting application context with
`D` opaque; its other operations are now safe data. If no source
activation occurs at all, the initial safe algebra already fails.
A functional data result has no `c`; an ordinary
rigid result retains final `T`; and a result headed by `D` with
an internal argument is the already excluded case. If the result
is bare `D`, its three external arguments give

```
D F Pₘ₋₁ T →* T,
```

which is not the required output. Thus the four-lambda case also
fails. This excludes every nonleading four-application candidate
having exactly one bound-variable leaf.

## Two bound leaves in a nonleading four-application handler

Consider the other nonleading case: the five leaves are exactly
`s,j,c,v,w`, where `v,w` are bound occurrences, possibly of the same
binder. There is only one free `s`. The size constraint gives either
`L=3,X≤6` or `L=4,X≤4`.

The normal source has the form

```
H = s D A₂ ... A_k,             1≤k≤4.
```

The first argument `D` must begin with a lambda. Otherwise its normal
head is `j/c`, since the unique `s` is already the outer head, and
the zero evaluation has the wrong rigid head. Expanding that outer
zero cell leaves the ordered input list

```
D K R A₂ ... A_k K R Q,         Q=K R.
```

There are `n=k+4` input application edges. Distinguish these edges
from fixed applications inside the source arguments.

### The ordered input edges

Until consumed, the input edges remain on the outer application
spine in their original order. A head contraction may insert fixed
source-body applications before the remaining input suffix, but it
cannot move an existing input edge inside an argument. In particular,
an earlier common argument `A_i` that reduces to `j` cannot remain
as the final application `R j` while the later `Q` edge is still
outside it. Consuming that later edge first requires the earlier
prefix to expose a lambda, which consumes the earlier input edges.

Since `Q` is a lambda and is not beta-equal to `j`, the zero result
`R j` cannot retain the last input edge. Consequently it retains
none of the original input edges. Its application to `j` comes from
a fixed source-body application, after all `n` input edges have
been consumed.

A source block with no remaining bound-variable occurrence consists
only of vacuous lambdas and rigid `j/c` leaves. It can discard inputs
or expose its fixed rigid head; it cannot put an input `R` into the
function position of a fixed source-body application. That requires
a live bound occurrence. The final useful live occurrence on a
successful zero path must therefore expose an input `R`, or expose
`Q` and apply it to fixed source arguments to obtain `R j`.

### Repeated occurrences of one binder

First suppose both bound leaves belong to the same binder `v`.
Before that binder is activated, only vacuous source lambdas can
consume the ordered input list: there is no other live binder that
could expose a supplied `K` or forward a supplied source closure.
Since `n≥5` and `L≤4`, `v` cannot receive the final `Q`.
Its argument is therefore `K`, `R`, or a common source argument
containing only rigid `j/c` leaves and vacuous lambdas.

An argument of the last kind eventually exposes a `j/c` head or
leaves a lambda; copying it cannot introduce an `R` head. Giving
`v` the rigid `R` exposes that head before the final input edge
has been consumed. The remaining source lambdas are vacuous, and
there are fewer of them than remaining input edges, so that rigid
head retains a nonempty suffix ending in `Q`.

If `v` receives `K`, all subsequent reductions select or erase
subtrees: the only live functional binders are those of copies of
`K`, and every remaining source lambda is vacuous. These reductions
preserve the order of surviving rigid leaves. If `j` lies inside
`D`, it precedes every still-available `R`, so the result cannot
be `R j`.

If `j` lies in a common argument `A_i`, every original input edge
must still disappear by the ordered-suffix invariant. A fixed source
application inside `D` contains no `j`, while a fixed application
inside `A_i` contains no `R`. Selector and eraser reductions cannot
insert a received input into either fixed application: `K` returns
its selected argument whole, and a vacuous lambda discards its
argument. Thus joining a pending input `R` to that common `j`
would have to retain an original input edge, which is impossible.
This excludes the repeated-binder case without counting how many
vacuous lambdas its contraction might copy.

### Distinct affine binders

Now suppose the two bound leaves belong to distinct binders. All
source binders are affine, so neither source nor data reduction
copies any source lambda. There are at most `L` source-lambda
contractions and two live source occurrences on the head path.

Before the final useful occurrence, the other occurrence can expose
at most one useful `K` head. Forwarding a common argument containing
the other occurrence merely advances to that occurrence. Exposing
an `R` too early makes the head rigid while the final input suffix
remains. A source `j/c` block has the wrong head.

A final live occurrence that instead exposes `K` cannot produce
`R j`. If its first selected operand is a fixed source block, that
block either has a fixed `j/c` head or would require a further live
capture of `R`. If selection reaches the pending inputs, selecting
the earlier cell `R` retains a suffix ending in `Q`; selecting the
last external `K` gives `K R Q→R`, with no source `j` after it.
Vacuous wrappers only discard inputs and do not change this order.
Thus at most one useful `K` contraction precedes a successful
`R j`. A source lambda consumes at most one original input edge,
and that `K` consumes at most two. The ordered-spine invariant gives
the necessary inequality

```
L+2 ≥ n=k+4,             hence L≥k+2.
```

### The equality cases

If `L=3`, the inequality forces `k=1` and equality. The useful
`K` must then consume two original input edges; a fixed source
argument to that head would use one of its contractions without
consuming an input edge. Hence its source head has no fixed argument
spine: `D` is a one-leaf projection, and the other live occurrence
must lie in a common argument `A_i`. There is no common argument
when `k=1`. This is impossible.

If `L=4`, the inequality leaves `k=1,2`. For `k=1`, both `j,c`
lie inside the leading lambda of `D`, already giving `X≥5>4`.

For `k=2`, equality again makes `D` a one-leaf projection and puts
the other live occurrence in `A₂`. The only projection that can
expose that argument through the useful `K` is

```
D = λa b.a.
```

It consumes the cell's `K,R`, then uses that `K` to select `A₂`
and discard the external `K`, leaving `A₂ R Q`. A one-lambda
projection returns the cell `K` too early and selects the cell
`R`; a projection consuming three or more inputs either loses
`A₂`, returns a rigid input, or leaves too few source lambdas for
the remaining live occurrence.

Both `j,c` and the remaining two lambdas lie in `A₂`. Its single
live occurrence cannot expose an `R` head with `Q` still pending;
therefore both lambdas must be leading to obtain `R j` from
`A₂ R Q`. The two rigid leaves then contribute at least `3+4=7`
to `X`, and the outer-variable occurrence in `D` contributes one
more. This contradicts `X≤4`.

Hence the two-bound-leaf case also cannot meet the 30-bit budget.

## One leading lambda in a four-application handler

The only remaining normal shape has `A=4,L=3` and exactly one
leading lambda:

```
H = λb.B,                  X≤6.
```

Mandatory occurrences of `j,c` contribute `2+3=5` index units,
leaving at most one extra unit. Each occurs exactly once; an
additional occurrence would itself exceed that allowance. Higher
ambient variables are also excluded. Let `V=Pₘ₋₁(N)` and `Q=K N`
on a sufficiently long variable stream. The variable law becomes

```
B[F/b] V Q =β c V N.
```

### A free stream occurrence

If free `s` occurs, its index one spends the entire remaining unit.
Thus `j,c,s` have no inner lambda above them, every bound-variable
leaf has index zero, and there is only one `s`. The two inner
lambdas contain only their own bound leaves. The five-leaf budget
leaves exactly these possibilities:

* two separate identities `I,I`;
* `F=λa d.d`, with the other bound leaf an exterior occurrence of `b`;
* `J=λa.a I`;
* `G=λa d.d d`.

These exhaust the closed normal blocks with two lambdas and at most
two variable leaves whose indices are all zero. The remaining
syntax is application-only over those blocks, the stream, the
possible exterior `b`, and rigid `j,c`.

After substituting `b=F`, the first two possibilities belong to the
safe data algebra. Functional results contain no `c`, while a
rigid result retains both pending arguments and ends in `Q`.
Neither can produce `c V N`.

Each of `J,G` uses both remaining bound leaves, so there is no
exterior `b` in these cases. Before any source activation, the
application context has only `S=Pₘ`, rigid `j,c`, and its unique
opaque source block. The earlier literal-`s D` argument applies:
if an activation occurs, a first one can be chosen at a literal
source subterm `s J` or `s G`. If none occurs, the data or rigid
result already fails with both external arguments pending. The
two possible local activations give

```
S J →* F I V → V,
S G →* (λd.d d) V → V V →* Q.
```

Both eliminate all inner source lambdas and leave only safe data
before the pending `V,Q`. The data-algebra obstruction completes
the free-`s` case using the variable law alone.

### No free stream occurrence

Without `s`, all three leaves besides `j,c` are bound occurrences.
First-input dependence and beta-normality force the body head `b`:

```
B = b A₁ ... A_q,             1≤q≤4.
```

For `q=1`, the variable input `F` erases the only argument and
therefore erases the sole source of `c`. For `q=4`, every argument
is a lambda chain over one leaf. The zero branch uses only
projections, constant chains, and supplied copies of `K`. These
select or erase subtrees while preserving the order of surviving
rigid leaves. Every source `j` precedes every external `R`, so
they cannot give `R j`.

For `q=2`, zero selects `A₁ R (K R)` and the variable branch
selects `A₂ V Q`. The unique `j` must lie in `A₁`, and the
unique `c` in `A₂`. Each branch also needs a bound-variable
leaf: without one the first is a vacuous `j` chain, and the
second is a vacuous `c` chain whose nonempty final argument
suffix ends in `Q`. Thus each branch has exactly two leaves and
one internal application.

The single spare index unit permits at most one inner lambda
above `j`. The only useful normal forms for the first branch,
up to placement of lambdas elsewhere, are

```
b j,                b (λu.j),                λu.u j.
```

On the zero input their results after `R,K R` are respectively
`j (K R)`, `j`, and `R j (K R)`, all wrong. Every other
placement has rigid head `j`, puts `j` beneath two inner
lambdas, contains a source beta redex, or captures outer `b`
beneath a lambda also containing `j`. That last placement costs
two spare index units, one for `b` and one for `j`, exceeding
the available one.

For `q=3`, exactly one application lies inside the arguments.
If it lies in `A₂`, the zero branch `A₁ A₃ R (K R)` uses
only projection and constant chains. The same rigid-leaf order
obstruction excludes it.

Otherwise `A₂` is a lambda chain over one leaf. If it is bare,
that leaf is `j`, `c`, or outer `b`. The first two give a wrong
rigid head or retain the wrong final argument. The last becomes
`F`, and `F A₃ V Q→*V Q` has no `c`. If `A₂` begins with
a lambda, contract `A₂ A₃` internally on the variable branch.
Its one-leaf body is affine, so at most one source lambda remains,
with both `V,Q` still pending. The affine pending-argument lemma
then excludes the required result.

The only way that this residual could instead be nonlinear is
for `A₃` to contain both remaining bound leaves under its sole
lambda. In that case the other two leaves `j,c` lie separately
in `A₁,A₂`; zero correctness puts `j` in `A₁`. That first
branch is a vacuous rigid-`j` chain and already fails the zero
law. Thus the affine argument covers every remaining case.

This excludes the one-leading-lambda shape at the 30-bit budget.

## Affine handlers without whole-stream access

The following handwritten theorem has been independently reviewed; it is not a
Lean theorem. It uses the `T=s` variable law alone and allows arbitrary affine
source beta redexes, but requires the handler to have no free `s`.

Let

    F = λa b.b,
    P₀(N) = λh.h K N,
    Pᵢ₊₁(N) = λh.h F (Pᵢ(N)).

A term is affine when every lambda binder has at most one occurrence. Count
every lambda and application in H, including any source redexes, as L and A
respectively. The free variables of H are fixed rigid ambient variables,
including c if used; H contains neither the stream variable s nor the fresh
suffix variable N.

**Theorem.** If H is affine, then for every integer m>A+2L+5,

    H F (Pₘ₋₁(N)) (Pₘ(N)) ≠β c (Pₘ₋₁(N)) N.

Consequently no affine handler without free s satisfies the whole-stream
variable law for every unary length. No zero-branch law, normal-form
assumption on H, or wire-size bound is needed.

### One-stream application-edge lemma

Let C[-] be an affine one-hole context with N absent, and place one P_b(N) in
its hole. Suppose a beta-reduction reaches a normal term containing N as a
bare leaf outside every residual original Scott cell. Then

    b+1 ≤ A(C),

where applications inside the inserted P_b(N) are excluded from A(C).

Give the initial applications of C persistent marks, and give the applications
initially inside P_b(N) no marks. Affine beta reduction never copies any
application node or N occurrence. Since the final term contains N, its sole
origin is never erased.

Every original Scott cell whose tail contains N must have its own lambda
contracted before N becomes bare. An uncontracted original cell is a
beta-normal subterm closed except for rigid N; no outside substitution can
change its body or extract its tail. Erasing it would erase the sole N.

We claim every such contraction consumes a marked application node. An
unmarked application belongs to a cell body

    (h bit) tail,

where bit is F or K. Before this cell's lambda contracts, its whole body is
normal. When that lambda contracts with callback a, the two application nodes
become

    (a bit) tail.

The unique N remains in tail, so a and bit contain no N. While the outer node
survives, that N stays in its argument subtree: reductions inside the argument
keep it there or erase it, reductions outside move the whole node, and a
substitution into the function cannot supply a second N. To move the argument
into a callback body, the outer node itself must contract and disappear. Thus
this outer node cannot ever have an N-containing residual stream as its
function.

The paired inner node a bit also cannot acquire N in its function. As long as
the paired outer node survives, N is confined to the other side. Before the
outer node can contract, its function a bit must become a lambda; this
requires the inner application node to contract or disappear first. It
therefore cannot survive that transfer and subsequently become an application
of an N-containing stream. Erasing the N-bearing tail instead would lose N
permanently.

There are no application nodes inside the Boolean bodies. These are all
unmarked origins. Consequently every original Scott-cell contraction consumes
a distinct initially marked node, proving the bound. This argument tracks
syntactic residual nodes, not the numerical size of an intermediate reduct.

### A long output spine retains an original cell

Assume the claimed reader equality. The whole application is affine, so it
beta-normalizes, and by confluence its normal form is the displayed normal
target.

Distinguish the two initial suffix occurrences as fresh rigid N₁ and N₂.
Replay the same reduction with those labels. Affinity prevents duplication,
and the target has two suffix occurrences, so neither origin was erased. The
labeled target is therefore

    c (Pₘ₋₁(Nα)) Nβ,           {α,β}={1,2}.

Every Scott binder on the outer spine of Pₘ₋₁(Nα) has body headed by its own
variable with exactly two arguments. At most L such binders can originate in
H. None can originate in an input Boolean:

* a surviving vacuous Boolean binder stays vacuous under capture-avoiding
  substitution;
* the live binder of F has body consisting of that variable alone, even after
  its vacuous outer binder disappears;
* the outer live binder of K, while it survives, retains its normal body λb.a;
  its inner binder is vacuous.

These are syntactic facts about surviving binders. No eta conversion is used,
and a Boolean merely being extensionally related to some term does not
suffice.

The output spine has m Scott binders. Since m>L, it contains an original
input-cell binder. Choose the first one from the outside, after d output
cells. All d preceding binders must originate in H, so d≤L. This original cell
is the intact subterm

    Pᵢ(Nα),             i=m−1−d ≥ m−1−L.

It is intact because the original cell was beta-normal and closed except for
Nα. Outside substitution cannot change it, and contracting its own binder
would destroy that binder's origin. The original input containing this cell is
either Pₘ₋₁(Nα) or Pₘ(Nα), so there are at most d+1≤L+1 cells above it there.

### Replace the retained island and apply the edge bound

Replace this original surviving cell by a fresh rigid variable z in the
initial term. Replay all the previous contractions outside its unique
residual. None contracted inside the cell, and none erased it; treating it as
opaque therefore preserves every contraction. Capture-avoiding shifts of z
follow the same surrounding binders as the replaced cell. The final target is
the same c-headed term with its retained cell replaced by z, and with Nβ still
a bare final argument.

The reserved input now has at most L+1 Scott cells, ending in z. The other
input is still P_b(Nβ), with b=m−1 or b=m, and has at least m cells. All of Nα
was inside the replaced cell and has disappeared. The remaining context around
P_b(Nβ) is affine, contains no Nβ, and has at most

    A + 3 + 2(L+1) = A+2L+5

applications: A in H, the three external reader applications, and two for each
cell of the truncated other input. Boolean bodies add no applications.

The one-stream lemma now requires

    m ≤ b+1 ≤ A+2L+5,

contrary to the chosen m. This proves the theorem. It excludes every affine
no-`s` handler for `T=s`, including affine reducts of non-affine source
handlers. It does not exclude handlers that retain a nonlinear binder or use
the whole stream freely.

## Compression constraints for the whole-stream operand

The following results concern `T=s` at its improving budget `|H|≤34`.
They do not assume that the first input is used: unlike `K R`, the
third input `s` itself still carries the branch bit.

### All-vacuous handlers still fail

The earlier head relation between `P=cons K R` and
`W=cons F (cons K N)` applies without change to source expressions
made from application, rigid ambient variables, and vacuous lambdas.
Only the external-argument calculation changes. An exposed `P` with
three, two, or one of the inputs `K,R,P` still pending gives

```
P K R P →* R,        P R P →* R K R P,        P P →* K R.
```

None is `R j`. A rigid head exposed while inputs remain retains the
last `P`, which is not beta-equal to `j`. Thus the zero law again
requires three successive constant-function heads, discarding the
three inputs, followed by rigid head `R`. The related variable
evaluation discards `F,cons K N,W` through the corresponding
constant functions and ends with rigid head `N`, rather than `c`.
This excludes all-vacuous handlers for `T=s` without a size bound.

### A growing affine contraction cannot belong to a successful handler

The exact affine size change remains

```
Δ = d(f−1) − 6 − r,
```

where `d` is the depth of the sole bound occurrence in the redex
body, `f` counts free leaves of its argument, and `r≥0` counts the
other body references whose indices decrease. Unlike at 30 bits,
this quantity can be positive at 34 bits. However, the same source
budget gives

```
3d+4f+7 ≤ 34.
```

Together with `d(f−1)>6+r`, this leaves only

| `d` | `f` | Lower bound `3d+4f+7` |
|---:|---:|---:|
| 4 | 3 | 31 |
| 5 | 3 | 34 |
| 3 | 4 | 32 |
| 2 | 5 | 33 |

Every row forces `A=f`: an additional application would add four
bits to a lower bound already at least 31. The `A+1=f+1` source
leaves are therefore exactly the sole bound occurrence `u` and
the argument's `f` free leaves. The redex body is `λ^d.u`, and
every lambda inside its argument `D` is vacuous. Both mandatory
rigid leaves `j,c` lie in `D`.

There is no surrounding application, since the redex and `D`
already use all `f` applications. There is no surrounding lambda
either: one would add two lambda bits and at least two index bits
for `j,c`, raising the lower bound to at least 35. Thus the whole
handler is the redex, and its contraction leaves only vacuous
source lambdas. The preceding obstruction excludes that reduct
and hence the original handler.

Consequently every affine contraction in a successful handler of
size at most 34 is nonincreasing in wire size. An affine contraction
also strictly decreases AST node count. Choosing a successful
handler minimal in `(wire size, AST node count)` therefore removes
every affine source redex, despite the failure of unrestricted
34-bit affine size monotonicity.

### Two source lambdas cannot fit the 34-bit budget

This exclusion does not require minimality. A normal handler with
two source lambdas already fails the variable law. In a nonnormal
one, an affine source contraction leaves at most one source lambda,
which also fails. Any source redex must therefore copy an argument
containing the other source lambda. Write the whole handler as

```
E[(λu.B) C[D]],             D=λv.W,
```

where `B,C,E,W` are application-only and `C` has one hole. Set
`k=#u in B≥2` and `r=#v in W`. The argument `C[D]` is
source-beta-normal: contracting a redex headed by `D` there would
leave at most the outer source lambda, because that redex's argument
contains no lambda.

The wire budget gives `A≤6`, hence at most seven variable leaves.
The two source lambdas are disjoint, so their bound occurrences
have index zero. If `r=0`, contracting the outer redex leaves only
vacuous source lambdas and is impossible. If `r=1,k=2`, that
contraction leaves affine source code with at most two lambdas.
Its ordinary beta-normalization cannot increase the lambda count,
so the normal three-lambda floor excludes it, irrespective of the
normal form's wire size.

First suppose no free `s` occurs. If `D=I`, the remaining source
reduces through the application algebra of `I` and rigid variables.
Otherwise `W` either has a rigid head or has head `v` with at least
one argument. In an application tree over copies of `D` and rigid
variables, a head contraction of an applied `D` then either exposes
a rigid head or produces another applied `D`. It cannot expose a
bare lambda: substituting the argument at the head occurrence of
`v` retains at least one body argument. Thus a nontrivial such tree
has a rigid head or no head normal form. A proper normal `C[D]`
is already rigid-headed; a bare `C[D]=D` yields a nontrivial tree
because `k≥2`. The surrounding application-only context cannot
repair either outcome. A rigid head retains all three external
arguments, while an exposed divergent head cannot yield the required
normal output. This handles the no-`s` cases.

Now suppose `s` occurs. The mandatory `j,c,s` leaves give
`k+r≤4`. After the preceding cases, only `(k,r)=(3,1)` and
`(2,2)` remain. Both use all seven leaves, so

```
A=6,             X≤4.
```

There is exactly one occurrence of each ambient variable `j,c,s`.
Since their base index contribution is three, at most one ambient
leaf lies beneath either source lambda.

For `(k,r)=(3,1)`, if `D=I`, substitution reduces to the safe
application-only data algebra. Otherwise the sole ambient leaf
beneath a lambda lies in `D`, which is one of

```
R_a=λv.v a,                 L_a=λv.a v,          a∈{s,j,c}.
```

Then `B` is a pure three-leaf tree of `u`. The extended data
algebra for `R_a,L_a` proved above reduces `C[D]` to base data,
to a rigid neutral, or to `D` itself. Only the last case needs an
additional check. For `a=s`, `D D→*Q=K N`, and either three-copy
tree is `N`-headed. For rigid `a`, `D D` and either three-copy
tree have head `a`. All outcomes therefore return to the base
data or rigid-head obstruction.

For `(k,r)=(2,2)`, choose an arbitrarily large **odd** prefix
length `m≥3` and write

```
S=Pₘ,       V=Pₘ₋₁,       U=Pₘ₋₂,       Q=K N.
```

The adjacent-pair identities on this subsequence are

```
S V →* N P₀,                 U V →* N P₀.
```

They follow by applying the recursive pair/pair row twice, reducing
both indices by two, until `P₁ P₀→N P₀`. Parity is essential:
the corresponding adjacent products at even `m` are `I`.

If `s` is inside `B`, then `D=Δ=λv.v v`. For a bare argument
`C[D]=D`, the six possible three-leaf bodies give

| Body `B` | Result after `u:=Δ,s:=S` |
|---|---|
| `u (u s)` | `N` |
| `u (s u)` | `Q` |
| `s (u u)` | no head normal form |
| `(u u) s` | no head normal form |
| `(u s) u` | `N` |
| `(s u) u` | `U` |

A proper `C[D]` has only rigid ambient heads in this case and
already fails by the same data argument. Thus this placement cannot
satisfy the variable law.

If `s` is inside `D`, then `B=u u`; a proper `C[D]` is again
rigid-headed. For the bare argument, the six bodies of `D` give

| Body `W` | Head behavior of `D D` at odd `m≥3` |
|---|---|
| `v (v s)` | `N`-headed |
| `v (s v)` | `N`-headed |
| `s (v v)` | no head normal form |
| `(v v) s` | no head normal form |
| `(v s) v` | `N`-headed |
| `(s v) v` | `N`-headed |

For the second row, `S D→*V`, so `D D→*V (S V)`.
For the last row, `S D→*U V`, so the adjacent-pair identity
gives its rigid `N` head. The two divergent rows respectively
return to `D D` with two or one further arguments. These are head
loops, independent of reductions inside their arguments.

Finally suppose `s` lies outside both lambdas. Then `D` is `Δ`
or has one rigid leaf `a∈{j,c}` in addition to its two `v`
leaves. The alternative placement of that rigid leaf in `B` leaves
`D=Δ`. With `D` opaque, any first source activation inside
`C[D]` must occur at a literal `s D`, by the earlier first-activation
argument. For `Δ`, this gives `S Δ→*V`. For the six bodies
`v(v a),v(a v),a(v v),(v v)a,(v a)v,(a v)v`, respectively,
the results of `S D` are

```
V,       V,       a-headed,       a-headed,       I,       a-headed.
```

Thus a proper `C[D]` reduces to safe data or a rigid neutral.
Substitution into `B` preserves the base algebra. If `C[D]` is
bare `D`, the nontrivial tree `B[D/u]` uses only `D` and rigid
variables, and the applied-`D` invariant above gives a rigid head
or head divergence. The remaining application context may erase
such a term, but doing so leaves base data or an ordinary rigid
head; retaining it as the head preserves divergence. None produces
the required two-argument `c` spine after all three external inputs.

These cases exhaust the two-lambda source shapes. Therefore every
successful `T=s` handler of size at most 34 has **at least three
source lambdas, even before beta-normalization**. Its size identity
then forces **at most five applications**.

### Four-application nonlinear compression

Choose a successful handler minimal in `(wire size, AST node count)`.
It has no affine source redex by the preceding size argument. Suppose
it has a nonlinear source redex and at most four applications.
At three applications the mandatory `j,c` and two occurrences of the
redex binder exhaust the four leaves. Contracting that binder leaves
only vacuous source lambdas, which cannot satisfy both laws. Fewer
applications cannot contain all four mandatory leaves.

At four applications there is only one further leaf. Unless it is
the occurrence of another live source binder, contraction again
leaves only vacuous binders. The only case to consider therefore
has exactly the leaves

```
u, u, j, c, v,
```

where `u` is bound by the chosen nonlinear redex and `v` is the
sole occurrence of a distinct live binder. In particular `s` is
absent. If the redex argument does not contain both the binder of
`v` and its occurrence, contraction leaves at most one live source
binder. All other source binders are vacuous. Such source code has
a beta-normal form: a contraction of its only live binder leaves
all-vacuous code, while vacuous contractions strictly remove syntax.
Its normal form still has at most one live binder. The no-`s`,
one-live-binder obstruction proved in the following normal-handler
section excludes this normal form, regardless of its wire size.

Otherwise let `D` be the entire copied argument. It has one live
binder, used once, and every other binder inside it is vacuous.
Its only possible free variables are `j,c`. Since every binder
inside `D` is affine and the minimum handler has no affine source
redex, `D` is source-beta-normal.

Contract the `u` redex. There are now exactly two copies of `D`,
and all remaining source binders are affine. Normalize this source
term before supplying any reader inputs. Affine beta reduction
terminates and cannot increase the number of live binders. If one
of the two live binders contracts, loses its sole occurrence, or is
erased with a surrounding subtree, the resulting normal form has
at most one live binder and is excluded as above.

Suppose both live binders survive. No live contraction occurred;
every source contraction was vacuous. Mark each surviving live
binder together with its body as an island. Initially the two
islands are disjoint copies inside the two occurrences of `D`.
Vacuous contractions only remove an argument and expose an already
present body: they cannot insert either island inside the other.
The source-normality of `D` also prevents an internal redex from
altering an island. Removing a vacuous prefix of a copy does not
change the island rooted at its live binder. The two surviving
islands therefore remain disjoint in the full source normal form.

A beta-normal term without `s` has a rigid head or a head variable
bound by one of its leading lambdas. A rigid head cannot give the
zero output `R j`. A bound head would make its binder live, so
that binder must be one of the two surviving islands. Being on the
leading lambda chain, its body contains the rest of the normal
term, including the other surviving live binder, unless that
other binder is earlier on the leading chain. In the latter case
the reverse containment holds. Either case nests the two islands,
contradicting their disjointness. If `D` was originally headed by
rigid `j/c` instead, that rigid head already guards its live binder
and cannot provide a leading bound head.

Thus the normal form fails in every case. A minimum successful
whole-stream handler with four applications must be beta-normal;
only five-application nonlinear compression remains at this budget.

### The remaining five-application compression shapes

At `A=5`, the improving budget and the source-lambda floor give

```
L=3, X≤6,              or              L=4, X≤4.
```

Choose a nonlinear redex with binder `u`. Its two mandatory bound
occurrences and the rigid `j,c` use four of the six variable leaves.
If every other source binder is vacuous, contracting `u` leaves
all-vacuous code and fails.

When `s` is absent and there is at most one other live binder,
the live-binder-antichain theorem below excludes the reduct. If
that binder lies inside the copied argument, its copies are
disjoint live islands and every other binder is vacuous. Otherwise
only that one live binder remains, possibly with more occurrences.
This includes a third occurrence of `u`, a repeated occurrence of
the other binder, and an additional rigid ambient leaf.

If `s` is present, the only remaining leaf allocation is

```
u,u,j,c,s,v,
```

where `v` is the sole occurrence of a distinct live binder. The
post-contraction code has stream access, so the no-stream theorems
do not settle this allocation.

If `s` is absent, the only remaining allocation is

```
u,u,j,c,v,w,
```

with `v,w` bound by distinct affine binders. After contracting `u`,
the affine no-stream theorem excludes the reduct whenever it is
still affine. It can become nonaffine only if the copied argument
contains a free occurrence of `v` or `w` whose binding lambda lies
outside that argument. The following argument excludes these last
enclosing-binder placements as well.

For `L=4`, the bound `X≤4` permits no initial leading lambda:
the mandatory `j,c` below one would already contribute five.
Follow the source's left application spine. A rigid head fails the
zero law. A lambda at its head must bind `u`, since every other
source binder is affine and the minimum has no affine source
redex. Thus the `u` redex lies on this application spine, with no
enclosing lambda. Its argument cannot contain a free occurrence
bound by another source lambda: such a binder would have to enclose
the redex. The reduct is therefore affine and already excluded.

For `L=3`, call the copied argument `D`. If it contains no lambda,
contracting `u` leaves at most two source lambdas. The unrestricted
no-`s` two-source-lambda corollary below excludes that reduct.
Otherwise `D` contains one of the other two binders, say `b`, and
the copied free occurrence is bound by the remaining binder `a`
outside `D`. Thus `a` encloses the `u` redex and also encloses
`b`: all three source lambdas lie in this one `a` block.

The `a` block must be the whole handler. If it is applied in
function position, it gives an affine source redex, forbidden by
minimality. If it is in argument position, all source lambdas are
inside that argument and the outside head is rigid `j/c`, which
cannot satisfy the zero law. Consequently `H=λa.T`.

On the variable branch, first substitute the closed affine Boolean
`F` for `a`, then contract the source `u` redex. Call the resulting
term `T_F`. The binder `b` is inside `D`, so its copies remain affine;
the only formerly free bound occurrence in `D` has become `F`.
Every lambda in `T_F` is therefore affine, and `T_F` has no free `s`.
The affine handler

```
H′ = λignored.T_F
```

has exactly the same variable behavior as `H`:
`H′ F Pₘ₋₁ Pₘ =β H F Pₘ₋₁ Pₘ`. The affine no-stream theorem
excludes this equality for all sufficiently large `m`. No zero law
for `H′` is needed. This closes the final no-`s` placement without
requiring a special shape for `D`.

Thus all no-`s` five-application nonlinear compression is excluded.
The only remaining compressed allocation at the improving budget
is `u,u,j,c,s,v`, with `v` bound by one affine source lambda.

### Four lambdas cannot fit the remaining compressed allocation

The following handwritten exclusion has been independently reviewed. It
uses the same rigid ambient frame and reader laws. Write `P=cons K R` on
the zero branch, whose target is `H K R P =β R j`; the variable target
remains `H F V S =β c V N`.

Assume a minimum successful handler at at most 34 bits has A=5, L=4 and
the sole remaining leaf allocation

    u,u,j,c,s,v.

The chosen redex is (lambda u.B) D, u occurs twice, and v is the sole
occurrence of a distinct live binder. The other two source binders are
vacuous. There is no affine source redex. In particular D is beta-normal.
Write d for the number of lambdas in D.

#### The index budget as a sum of taxes

The mandatory ambient indices contribute 1+2=3. For a source lambda l,
let its tax count every variable leaf in its body whose binder lies outside
l, including ambient leaves, but excluding leaves bound by l itself or by
an inner lambda. Then

    X-3 = sum_l tax(l) <= 1.

Thus at most one source lambda has positive tax, and that tax is one.
A vacuous lambda with tax zero must enclose a live source binder: otherwise
its nonempty body would have a free leaf. Only u and v are live. If such a
lambda encloses u, it also encloses the argument D, since u is already an
applied source lambda. If it encloses v inside D while itself lying outside
D, it encloses all of D.

Consequently, if D is nonclosed and contains the binder v, every vacuous
lambda outside D has positive tax. Also, no initial leading lambda is
possible: j,c beneath it would already contribute X>=5. A leading lambda
in B is impossible too, because both u occurrences would cross it and
consume two extra index units.

For use with singleton arguments, the exact wire change when contracting
u is

    Delta = |D| + (f-1)(d1+d2) - 8 - r,

where f counts free leaves of D, di is the depth of the i-th u occurrence
below its binder, and r counts other body references whose index drops.
For a singleton lambda-free D, f=1 and |D|<=5, so the contraction strictly
reduces size. Closed I and F arguments similarly give a strict decrease.

#### d=0

A singleton D is excluded by the strict wire decrease. Suppose D has at
least two leaves. If it contains free v, the binder v encloses D and at
least one ambient leaf, so tax(v)>=1. Both vacuous lambdas must then have
tax zero. Neither can enclose v, since that would also enclose the ambient
leaf. Neither can enclose u without v, since its body then contains both
the free v and that ambient leaf in D. There is no other live binder for
a zero-tax vacuous lambda to enclose. This is impossible.

Thus D contains only ambient leaves. If j is in D, its zero specialization
has j permanently guarded in a rigid j/c-headed neutral. Indeed D is an
application-only expression with distinct leaves from s,j,c and at most
one s. A head j/c stays rigid; a head P receives a j/c-headed callback and
also becomes rigid. Every j is beneath an application headed by j or c.
Neither duplication nor application can extract a bare j from this normal
neutral, whereas the zero target requires precisely a bare j.

Otherwise D is exactly s c or c s, and becomes c-headed on the zero input.
All s occurrences are in D. Following the source's left spine, a rigid j
head fails immediately, while a lambda head must be the u redex: there
is no initial leading lambda and no affine source redex. B has no leading
lambda, and its head is u or a rigid j. A free enclosing v would place both
ambient leaves of D beneath v and cost two tax units. Hence after u
contracts the zero head is c or j, never R.

#### d=1, with v bound inside D

If D is closed, it is I and its contraction strictly reduces size.
If D is nonclosed, both remaining vacuous lambdas lie outside D and each
has positive tax by the index observation. This exceeds the sole spare unit.

#### d=1, with the lambda of D vacuous

The vacuous lambda in D has positive tax. If D contains free v and any
ambient leaf, tax(v) is positive as well, impossible. With no ambient leaf,
D is lambda q.v, whose size is at most five and f=1; contracting u strictly
reduces size.

Otherwise D contains no v. Its vacuous lambda must be exactly lambda q.a
for one ambient a; placing a second free leaf beneath it would already
cost two units. The remaining vacuous lambda has tax zero and must enclose
v in a closed block. That block is F=lambda q v.v: putting its vacuous
lambda below the live v would add a second tax unit. It cannot enclose u,
because D is nonclosed. The F block is disjoint from D.

If D is just lambda q.a, its size is at most seven, f=1, and contraction
strictly reduces size. Otherwise D is an application-only normal context
over ambient leaves and lambda q.a. The latter cannot be in function
position. Its zero specialization is therefore j/c-headed: a head P either
receives lambda q.a and yields a R, with a=j or c, or receives an already
rigid callback.

If j occurs in D, it is guarded and cannot supply the bare target j.
Otherwise D uses s,c and becomes c-headed. All code outside its two copies
is application-only over F,j and those c-headed neutrals. The functional
normal forms of this little algebra are only F and I; every other result
is rigid-headed. The final K,R,P give F K R P -> R P and I K R P -> R.
A rigid result keeps its final P. None gives R j.

#### d=2, with v bound inside D

If D is closed, its two lambdas form F or K. F has strict negative wire
delta. K spends the spare index unit, so no ambient can lie in B and both
u occurrences have depth zero. Thus B=u u, and contracting the core gives
K K. The outside vacuous lambda must have tax zero. It cannot sit inside
B above a u, nor above any ambient leaf. It therefore surrounds the whole
closed redex, giving the one closed block

    Z = lambda q.((lambda u.u u) K) ->* lambda q.K K.

All three ambient leaves lie outside Z. Since the original handler has no
affine source redex, Z occurs only in argument position. Its only possible
activation on zero is a callback use P Z, and

    P Z -> Z K R -> K.

Otherwise the head is already j/c. Replacing that activation by K leaves
an applicative expression over K,j,c with exactly one occurrence of each.
Its normal form has a j/c head, possibly below the one vacuous lambda of
K applied to a j/c-headed argument. The external K,R,P cannot change that
head to R. This excludes the closed K argument as well.

If D is nonclosed, the sole remaining vacuous lambda outside D has positive
tax and spends the entire allowance. Every lambda inside D has tax zero.
They therefore form the closed F block, and D is a normal application-only
context over that single F and ambient leaves. Also tax(u)=0, so B has no
ambient leaf; only the two u occurrences and possibly the outside vacuum
occur there.

On zero, a head P with first argument F yields R, possibly followed by
rigid arguments. Any other first argument is j/c-headed. Consequently D
becomes an R- or j/c-headed neutral; it never becomes a functional value.
If s occurs in D, all remaining syntax is application-only over these
rigid neutrals and j,c, with one vacuous lambda. At most one of the three
external inputs can be consumed by that lambda, and every exposed rigid
head retains a suffix ending in P. This cannot give R j.

If s does not occur in D, its normal j/c-headed value is independent of
the branch. It is a normal application containing j/c and the closed F
block, but no R or N. It cannot equal a subterm of R j: it is neither R,
j, nor R j. It also cannot equal a subterm of c V N. The target's neutral
c-headed prefixes contain N, while its remaining subterms are bare c/N,
the closed Booleans, or N-containing Scott subterms; none is this fixed
j/c-containing application. Outside reduction cannot dismantle D's rigid
head or alter its arguments. Thus every copy would have to be erased in
both successful target reductions. But D contains at least one of the
unique mandatory j/c leaves. Erasing all its copies removes every origin
of that free name. The zero target requires j and the variable target
requires c, so the corresponding branch is then impossible.

If both lambdas of D were vacuous and v lay outside, each would have
positive tax: no live binder is available inside D to make either body
closed. This directly exceeds the budget.

#### d=3: all remaining lambdas are in D

The normal lambda-block classification has three possibilities:

1. One closed three-argument projection P3, selecting the last argument
   (tax zero) or the middle argument (tax one). Selecting the first costs
   two units and is excluded.
2. Disjoint closed F and lambda q.a, where a is the sole ambient below a
   lambda. The latter vacuum has tax one.
3. One block lambda q.a F, where a is the sole ambient below a lambda.
   The outer vacuum has tax one; the inner closed F has tax zero.

Here is why these are exhaustive. A zero-tax vacuous lambda in D must
enclose v. If both vacua have tax zero, both enclose v and give the last
projection. A positive tax at live v would put an ambient beneath v and
therefore also beneath both zero-tax vacua, impossible. If one vacuum has
tax one because it encloses a free v, the other zero-tax vacuum surrounds
v and gives the middle projection. If it instead encloses an ambient a,
the zero-tax vacuum and v form F. This F is either outside that vacuum,
giving case 2, or inside its body. In the latter case source normality
forces the body a F, giving case 3. F a would be an affine source redex.

In cases 2 and 3, tax(u)=0 and there are no lambdas outside D, so B=u u.
In case 2 the two functional blocks can occur only as arguments to a
free head. A zero head P yields R followed by arguments if its first
argument is F, or a R followed by arguments if its first argument is
lambda q.a. Other callbacks are already j/c-headed. Thus D becomes a
rigid neutral, and D D remains rigid with an additional argument.
If D contains s, the outer context contains only j,c and cannot remove
that argument or the final external P. If it does not contain s, its
j/c head also guards it when the outer P uses it as a callback.

In case 3, a bare block with a=s becomes K R, and its self-product is R.
A bare block with a=j or c has a rigid self-product. A proper normal
application context has a free head. If that head is s, then a is j/c
and the callback gives a F R, still rigid; a j/c head is immediate.
Thus D D and its outside context again have a rigid head and cannot give
R j after all three external inputs.

For the last-argument P3 of case 1, a closed D has wire delta -r. If r>0,
contraction strictly decreases size. Otherwise B=u u, and D D reduces to
F; the resulting whole source has at most two lambdas and is excluded
by the normal two-lambda floor after affine normalization.
For the middle-argument P3, its tax already spends the extra unit,
so again B=u u. Its self-product is K, and the same two-lambda argument
excludes a closed D.

For a proper normal context around P3, its only possible functional zero
result comes from s P3. With the last projection this gives I, and adding
a further rigid argument makes the result rigid. With the middle
projection it gives K R, and any further argument exposes rigid R.
A head s with any other callback becomes j/c-headed; all other heads
are j/c from the start.

For the middle projection B=u u, so D D becomes R or a rigid neutral;
the outside context cannot give R j after K,R,P. For the last projection,
D is either already j/c-headed or is exactly s P3 and becomes I. In the
first case a remaining s, if outside D, receives only rigid callbacks and
also becomes rigid. In the second, s has been used inside D. Substitution
leaves an application-only expression over I,j,c. If the spare unit puts
one rigid a in B, that body's two I copies expose head a; otherwise
the I self-product is I. The remaining j,c context is rigid-headed.
This also fails the zero law.

Consequently five-application nonlinear compression at the improving
budget remains only with **three source lambdas**, `X≤6`, and the leaf
allocation `u,u,j,c,s,v`.

### Three lambdas with both remaining binders inside the copied argument

The following handwritten exclusion has been independently reviewed.
In the remaining compressed T=s allocation

    A=5, L=3, X<=6, leaves u,u,j,c,s,v,

a minimum successful handler cannot have both source lambdas other than u
inside the argument D copied by the chosen redex (lambda u.B) D. One of
these two binders is live and affine, binding v; the other is vacuous.
The claim allows every placement of the three ambient leaves s,j,c.
The normal-case obstruction uses only the variable law.

Because there is no affine source redex, D is beta-normal. Contracting u
leaves an application-only context of exactly two copies of D and whichever
of s,j,c were outside D. Every surviving source binder is affine. Call the
result H0. It is a nontrivial application tree; no source lambda lies
outside its two D copies.

#### Closed D

If D contains no ambient leaf, its sole variable leaf is v, so D=K or F.
The exact contraction formula is

    Delta = |D| + (f-1)(d1+d2) - 8 - r,

where f is the number of free leaves of D, di are the occurrence depths of
u below its binder, and r counts the other body references whose indices
drop. Here f=0 and |K|=7, |F|=6. Thus Delta<0, contradicting minimum wire
size. Hence D contains at least one ambient leaf in what follows.

#### A restricted application-headed affine observation

Use the established affine pending-argument lemma with this consequence:
a beta-normal application-headed affine source with k source lambdas fails
with n>=k pending safe reader arguments, ending in S=P_m, if its initial
exterior basis consists only of s and rigid markers. Choose m sufficiently
large relative to the fixed source.

Indeed, before any source activation, opaque source blocks cannot be
returned as bare functional values by this exterior basis. If no block
is activated, the result is safe data or a rigid neutral and fails. The
first activation consumes a source lambda without copying another. At
most k-1 source lambdas remain with n>=(k-1)+1 arguments pending, which is
the established affine pending-argument bound. The restriction on the
initial exterior basis is essential; arbitrary initial F/I could return a
bare source block without activation. If a leading vacuum has discarded
the first external F, this exterior basis is unchanged.

We use this only at (k,n)=(3,3) or (2,2). We also use the established
unrestricted affine bound at k<=2,n=3; that version allows safe data atoms.

#### Normalize H0 before substituting the reader input

Affine source normalization terminates. If two or more source lambdas
contract or are erased, at most two remain and the affine bound excludes
the result with all three external inputs pending.

Suppose exactly one source lambda is lost. The first source contraction
is a whole copy D applied to some X: D itself is normal, and all exterior
syntax is application-only. If its outer lambda is live, write

    D=lambda v.W.

The one-loss reduct is W[X/v]. Any leading source lambda of the full normal
result must have been exposed by this contraction, and this redex must
have been the entire H0; a surrounding application would require another
contraction to expose that lambda at the root. As v occurs once and W has
one other lambda, a lambda-headed W[X/v] can arise in only two ways.

First, W begins with the vacuous lambda q. Its body contains the unique v
and at least one ambient leaf, hence is application-headed before
substitution. If its head becomes the other bare D inside X, it has a
source argument and causes a second contraction. Otherwise its normal
body remains application-headed, with the other copy's two source
lambdas. The result has one leading vacuum followed by that body. After
the vacuum discards external F, the restricted (k,n)=(2,2) observation
excludes it.

Second, W could have head v with no argument, in which case substitution
could expose a bare lambda from X. But W=v has no place for either the
other source lambda or an ambient leaf, so this case is impossible.
If W has head v with an argument and X becomes lambda-headed, another
source contraction is required. If W has rigid head, substitution cannot
change it. This exhausts the ways to expose a lambda.

If D's outer lambda is vacuous, its first contraction erases X. Exactly
one loss requires X to contain no copy of D; the other copy survives
outside that redex. The exposed inner lambda therefore cannot be the
whole normal source: all initial exterior syntax was application-only,
and eliminating an exterior application would require another source
contraction. Hence the full source normal form is application-headed.

Every other one-loss case is likewise application-headed with three affine
source lambdas and is excluded by the restricted (3,3) observation.

Thus any remaining candidate has no source contraction at all: H0 is
already beta-normal, application-headed, and contains both intact D copies.

#### Lambda-headed D

If s lies inside D, the outside application tree has only j/c as rigid
leaves. Its head cannot be a D copy, since H0 is normal. Its head is
therefore rigid j/c, and retains all three external inputs. This fails.

Otherwise s lies outside D. All free variables inside D are j/c. If a
source lambda is ever activated before the external inputs, a first one
can be chosen at a literal source subterm s D, by the established first-
activation argument. If none is activated, safe data or a rigid head
receives all three external inputs and fails.

Let S=P_m and V=P_(m-1), with m sufficiently large. That activation is

    S D ->* D F V.

If D has two leading lambdas, both source lambdas are consumed. At most
the other copy's two source lambdas remain; the affine bound excludes the
result with all three external inputs still pending.

Suppose D has exactly one leading lambda. If it is vacuous, write
D=lambda q.W. W is application-headed and its head is rigid j/c: the live
binder is nonleading, and q is unused. The reduct W V has an immutable
rigid prefix whose first argument comes from W and contains no N.

If the leading binder is live, write D=lambda v.W. The other, vacuous
lambda is nonleading in W. If W has rigid head, W[F/v] V again has a
rigid prefix with an N-free first argument. If W has head v, write

    W=v A1 ... At,          t>=1.

There is no other occurrence of v, so every Ai contains only rigid j/c
and possibly the unique vacuous lambda. For t=1,

    F A1 V -> V

erases that lambda. For t>=2 the result is

    A2 A3 ... At V.

If A2 is lambda-headed, its vacuous lambda consumes the next argument
(V when t=2), eliminating the second source lambda. If A2 is rigid-headed
with a nonempty spine, its first argument is N-free. If A2 is a bare rigid
and t>=3, A3 is its N-free first argument. If A2 is bare and t=2, the
vacuous lambda had to lie in A1 and has already been erased.

Consequently every activation either loses both source lambdas of the
activated copy, or produces a rigid normal prefix with an N-free first
argument that permanently guards its remaining source lambda. Normalize
the arguments of this prefix; they are affine, and its first argument
remains N-free.

The prefix matches no subterm of the required target c V N: a j-headed
prefix is impossible because j is absent; a c-headed prefix has first
argument unequal to V, since V contains free N. Its rigid normal head and
arguments cannot be changed by outside reductions. Any successful trace
must erase it. Replace this entire prefix by a fresh rigid atom and replay
the outside trace. Only the other copy's two source lambdas remain, and
the unrestricted affine pending-argument bound gives a contradiction.
This is an erased-prefix replay, not contextual equivalence.

This handles every lambda-headed D, with any number of ambient leaves.

#### Application-headed D

If D has rigid head j/c and s lies inside it, all leaves in the exterior
application tree are rigid-headed, so H0 already has rigid head j/c and
retains all three external inputs. If s lies outside D, each copy of D is
a fixed normal j/c-headed application containing no N. Its nonempty first
argument is N-free, so the same erased-prefix argument freezes both copies.
The residual is application-only over s and rigid markers, and fails the
base data-algebra obstruction.

It remains that D has head s. There is exactly one occurrence of s, so

    D=s A1 ... Ak,          k>=1,

and each Ai contains only j/c and the one live binder v plus one vacuous
binder q. The two binders may occur together or in different arguments.
All Ai are source-normal. We claim that, after s=S is substituted, D
normalizes to exactly one of these three kinds:

1. a safe functional data value from the base algebra;
2. a rigid j/c-headed neutral (its arguments may contain source lambdas);
3. a constant lambda q.J, where J is a fixed N-free application-only
   expression over j,c.

If A1 is application-headed or a bare variable, its head is rigid j/c;
S A1 -> A1 F V is already rigid-headed. So assume A1 is lambda-headed.

If A1 contains both source lambdas, the analysis of A1 F V is the same
as the lambda-headed case just given. When both lambdas disappear, the
residual is application-only over safe F,V and rigid j/c, hence base-safe
or rigid. A guarded surviving lambda gives a rigid head. All later Ai
are application-only over j/c, so applying them preserves these two kinds.

If A1 contains only the vacuous lambda, its body is application-only over
j/c. Its invocation yields that rigid body followed by V, so it is rigid.
The live binder in some later Ai cannot change that head.

The remaining case is A1=lambda v.B, where B is application-only, contains
v once, and otherwise uses j/c. The vacuous lambda lies in a later Ai.
If B has rigid head, the invocation is rigid. If B=v B1 ... Bt with
t>=1, the Bi are application-only over j/c. For t>=2, F B1 ... Bt V
has rigid head. For t=1 it is V, but at least A2 remains because the
vacuous lambda lies outside A1. Applying V to an application-headed or
bare A2 gives a rigid head. If A2=lambda q.J, then V A2 -> J P_(m-2),
also rigid. Here J is application-only over j/c.

Finally B=v makes A1=I and S I -> I. Thus D reduces to

    A2 ... Ak.

These source-normal arguments together contain just one vacuous lambda
and rigid j/c. A functional result is possible only when k=2 and
A2=lambda q.J itself: it is kind 3. If another argument is present, that
lambda discards it and exposes rigid J. If A2 is application-headed or
bare, its head is already rigid. This proves the three-kind classification.

Now normalize each identical D copy before any external input is supplied.
The whole H0 is a nontrivial application tree over those two results and
the remaining rigid j/c leaves. For kind 1 the base data algebra applies;
functional results contain no c, while rigid results retain three external
inputs. For kind 2 every possible head is rigid before those inputs. For
kind 3 any applied copy lambda q.J immediately exposes rigid J, and the
whole tree is nontrivial, so again its normal head is rigid. Every case
fails the variable law.

This exhausts D and proves the d=2 exclusion for L=3. Any remaining
compressed handler has zero or one source lambda in its copied argument D.

### Three lambdas with one binder inside the copied argument

This handwritten exclusion has also been independently reviewed.
The setting is the remaining minimum T=s handler with

    A=5, L=3, X<=6, leaves u,u,j,c,s,v.

The source redex is (lambda u.B) D, u occurs twice, v is the sole
occurrence of the other live binder, and the third source binder q is
vacuous. There is no affine source redex. We claim that D cannot contain
exactly one source lambda.

The ambient indices contribute 3, and the remaining index units are the
sum of source-binder taxes:

    X-3 = tax(u)+tax(v)+tax(q) <= 3.

A binder's tax counts body leaves whose binders lie outside it. Because q
is vacuous and is the only lambda inside D whenever q lies there, it has
positive tax: its body is nonempty and every leaf is free relative to q.

We use the affine pending-argument bound and the restricted application-
headed consequence proved in the preceding section: an affine normal source
with at most two source lambdas fails with three pending reader arguments;
an application-headed affine normal source with k lambdas and initial
exterior basis s plus rigid markers fails with n>=k pending arguments.

#### The lambda inside D is the live binder v

Contract u. There are two normal affine D copies and one vacuous lambda
outside them. All three resulting source lambdas are affine.

If any source lambda contracts or is erased during source normalization,
at most two remain and the affine bound applies with all three external
inputs pending. Otherwise the post-u source is already normal with three
source lambdas. If application-headed, the restricted (k,n)=(3,3) bound
applies.

If it is lambda-headed, the leading lambda must be the exterior vacuum q.
A copied D cannot be exposed bare at the root without another source
contraction: the body B contains two u leaves and any exterior syntax is
applications and the single q binder. A body consisting of only u would
be required to substitute a bare D at the root. Thus the only possible
leading prefix is q. Its body is application-headed and has the two live
D copies. After q discards the external F, the restricted (2,2) bound
excludes that body. This exhausts the live-binder case.

#### The lambda inside D is vacuous, and v occurs freely in D

The v binder encloses the u redex, since it binds a leaf in D. Consequently
all three source lambdas lie inside the one v block V0=lambda v.W.
This block cannot be the whole handler: its tax would count all three
ambient leaves s,j,c, and the vacuous q already has positive tax, exceeding
the allowance 3. Nor can this initially affine v block be applied in
source function position, since that would be an affine source redex.

The handler is therefore an application-only context of the single V0
block and the ambient leaves outside it. If s lies inside V0, its exterior
head is rigid j/c and cannot satisfy the variable law. Otherwise s lies
outside V0. Before a source block is activated, the established literal-
stream argument applies to the exterior source: a first activation can be
chosen at a literal subterm s V0. If no activation occurs, safe data or a
rigid head receives all three external inputs and fails.

For a sufficiently long variable stream this activation gives

    S V0 -> W[F/v] V,          V=P_(m-1).

Now contract u inside W[F/v]. Its two copied arguments contain only the
one vacuous source lambda q and safe F plus rigid j/c. The result has at
most two source lambdas, both vacuous, with all three external inputs
still pending. The affine pending-argument bound excludes it. Any source
erasures only decrease this count. No nonlinear v remains: the v binder
was supplied F before u was contracted.

#### The lambda inside D is vacuous, and v lies outside D

Contract u. The result has two vacuous q copies and the original affine
v binder. It is affine. As above, any source contraction or erasure leaves
at most two lambdas and is excluded; a normal application-headed result
is excluded by the restricted (3,3) bound.

Only a normal lambda-headed result remains. A copied q block cannot become
the bare whole result without a source contraction, because B contains
two u leaves. Thus the leading binder is v.

The original handler cannot already have begun with v: that would give
tax(v)=3 from all three ambient leaves and tax(q)>0. The leading v must
therefore be newly exposed by contracting the whole root u redex:

    H=(lambda u.lambda v.T) D.

There is no other exterior application or lambda. Both u occurrences lie
below v and cost tax(v)>=2; q costs at least one. The index allowance is
therefore saturated:

    tax(v)=2,       tax(q)=1,       tax(u)=0.

No ambient leaf can lie in T. All three s,j,c lie in D, while T is an
application-only tree over exactly u,u,v. Since q is D's only lambda and
has tax one, its body is a single ambient leaf a. Thus q occurs in the
normal block K a=lambda q.a, for a one of s,j,c. D is application-headed
and is the normal three-leaf application tree over s,j,c with this one
leaf wrapped by the vacuum.

On the zero branch set P=cons K R. The specialization D0=D[P/s] has
rigid head j or c. If its source head is j/c this is immediate. If its
source head is s, its arguments use the two rigid leaves j,c, possibly
with one wrapped as K a. The first argument is either rigid-headed or
is K a for a=j/c. In the first case P appends K,R to that rigid head.
In the second case P (K a) -> a R, again rigid. A wrapped s could not be
the source head because D is source-normal. Further source arguments
preserve the rigid head.

After the first external K, the zero branch becomes

    T[D0/u,K/v] R P.

The tree T has two rigid-headed D0 leaves and exactly one K leaf. Its
normal form is rigid-headed, or is a single constant K J with J
rigid-headed. To verify this directly, any application whose function is
D0 keeps its rigid head. The only other function is the unique K; with
one argument it forms K J where J is built from D0 leaves, and with two
arguments it returns its first such rigid-headed argument. Neither D0
nor an application of D0 can discard the remaining K to return it bare.
Thus the pending R,P expose a j/c head, never the required R j.

This closes the final d=1 placement. Any remaining compressed L=3
candidate must have a lambda-free copied argument D.

### Three lambdas with a lambda-free copied argument

The following handwritten exclusion has independent exact review. Assume
the minimum successful whole-stream handler has
`A=5,L=3,X≤6`, no affine source redex, and leaves `u,u,j,c,s,v`.
The chosen nonlinear redex is `(λu.B) D`. Its binder occurs exactly twice;
the other live binder `v` occurs once in the source, and the third binder
`w` is vacuous. Suppose the copied argument `D` contains no lambda.

The claim excludes this entire `d=0` slice. It uses the variable law and
the source's exact index budget, without any candidate enumeration.

If `D` does not contain free `v`, contracting `u` leaves exactly two
source lambdas, both affine. The established affine pending-argument lemma
with `k=2,n=3` excludes the variable law. Every copied argument is
lambda-free; no other source binder becomes nonlinear.

Suppose `D` contains `v`. Its binder is outside the chosen redex and
encloses both `u` and `D`. A singleton `D=v` strictly decreases wire size
when `u` contracts: the contraction formula has `f=1`, hence
`Δ=|D|-8-r<0`. Here `v` crosses at most the sole vacuous binder on its
way to `D`, so `|D|≤3`. Such a source is not minimum. Thus `D` also
contains at least one ambient leaf.

Use the source index-tax identity `X-3=Σ tax(λ)≤3`, with the ambient
base contributions `j:1,c:2,s:0`. A leading `v` would have tax three,
since every ambient leaf would lie below it. The remaining vacuous binder
has positive tax. Indeed a zero-tax vacuum must enclose a live binder;
it cannot enclose its ancestor `v`, and enclosing `u` also encloses `D`,
including its free `v` and ambient leaf. A vacuum elsewhere has a free
leaf in its nonempty body. This exceeds the tax budget. A leading `w`
would likewise have tax three, while `v` has positive tax from the ambient
leaf in `D`. Thus the handler has no leading lambda.

The unique `s` must be its source head; a rigid `j/c` head fails. The
whole `v` block contains the only source redex and cannot itself occur
in source function position, since its binder is initially affine and
there is no affine source redex. The only other source lambda is `w`.
Its position relative to the `v` block is either inside, outside and
disjoint, or enclosing.

If `w` is inside the `v` block, the exterior has just that one lambda
block and the remaining ambient leaves. Since the unique `s` is the
whole source head, it is outside the block. Every other free exterior
head is rigid `j/c`. Hence a successful first Scott invocation must use
the literal `v` block as callback: a source application headed by `j/c`
stays rigid, and applying the `v` block in the callback's syntax would
have been an affine source redex. On a variable stream this first
invocation supplies `F` to `v`, followed by `V=P_(m-1)`.

Contract `v` with this `F` before contracting `u`. Now the lambda-free
argument `D[F/v]` contains only safe data and rigid variables. Contracting
`u` copies no source lambda and leaves only the single vacuous `w`.
The complete remaining expression is affine, with at most one source
lambda and all three external reader inputs still pending. The affine
pending-argument lemma excludes it. The additional Scott tail and source
common arguments belong to that remaining expression, not to the three
external inputs.

If `w` is disjoint from the `v` block, its body contains no live source
binder and no `s`, because the unique `s` is already the exterior head.
Its body is application-only over rigid `j/c`, so a first callback use
of `w` immediately gives a rigid head and fails. The first successful
callback must instead be the literal `v` block, receiving `F` as above.
Contracting `u` afterwards leaves the one disjoint vacuum. The same
affine `k≤1,n=3` contradiction applies.

Finally let `w` enclose the `v` block. It is the only exterior lambda
block. Again the unique `s` is outside it, and a successful first Scott
callback must be that literal block. Write it `λw.C[λv.W]`. Its first
argument `F` is discarded. If `C[λv.W]` is application-headed, its head
is rigid `j/c`: the only source redex is inside `λv.W`, and placing
that affine block in function position is forbidden. This case fails.
The only remaining shape is `λw.λv.W`. The same Scott invocation then
supplies its tail `V` to `v`. Contracting `u` after this substitution
again copies a lambda-free safe-data expression. No source lambda remains,
and the three external reader inputs are untouched. The base algebra,
equivalently the affine pending-argument lemma at `k=0,n=3`, excludes it.

These placements exhaust the source. Thus the lambda-free copied argument
cannot occur in a minimum successful handler in the remaining allocation.

Together with the preceding copied-argument cases, this excludes every
five-application nonlinear compression at the improving budget. A minimum
successful whole-stream handler of at most 34 bits is therefore beta-normal.

## Normal whole-stream handlers with at most three applications

Write `P=cons K R` on the zero input and `S=Pₘ(N)`,
`V=Pₘ₋₁(N)` on a variable input. The laws are

```
H[P/s] K R P =β R j,
H[S/s] F V S =β c V N.
```

The handler in this section is beta-normal. Let `k` count its
leading lambdas. Zero correctness gives `k≤3`. A rigid body head
cannot work. The established normal floor gives `L≥3`, and the
earlier whole-stream theorem already excludes `L=k=3` at this
budget. These facts will be used throughout the case split.

### No stream access and at most one live binder

First suppose `s` is absent and only one source binder is live,
possibly at more than one occurrence. Its body head must be a
variable bound by that binder, and the binder must be leading.
Otherwise the normal head is rigid. Every other source lambda is
vacuous.

If the live binder receives the first input `K`, only selectors
and vacuous erasers remain. Distinguish the remaining ordered input
edges carrying `R,P` from fixed applications in source bodies.
Selectors return an argument whole, and vacuous binders discard an
argument; neither inserts a received input inside a fixed source
application. The direct `R` cannot acquire the earlier source `j`
after the final `P` edge has been consumed. Before that edge is
consumed, an exposed rigid `R` retains `P`, so is not `R j`.
The final `P` can only be selected as a whole after the earlier
input edges have disappeared; there is then no later input or fixed
source argument to activate it. It remains a lambda. These cases
exclude the zero law.

If the live binder receives the second input `R`, two leading
lambdas leave final `P` attached to the rigid head. With three
leading lambdas, substituting rigid `R` creates no redex: all other
binders are vacuous and the source was normal. The normal result
still contains mandatory `c`, so cannot be `R j`.

If it receives the third input, all three leading lambdas have
been consumed. The remaining source expression uses only its
stream argument, rigid ambient variables, applications, and
vacuous lambdas. The all-vacuous head relation pairs the zero
stream `P` with a variable stream. A zero head `R` consequently
becomes head `N`, contradicting the variable head `c`.

Thus a normal no-`s` handler with at most one live source binder
fails, regardless of the number of that binder's occurrences.

### A live-binder antichain also fails

This consequence does not assume normality, affinity, or a size
bound. Call a binder live when it has at least one bound occurrence.
Suppose `H` contains no free `s`, and no live binder lies in the
body of another live binder. The condition refers to binding
identities and their residuals under capture-avoiding substitution,
not merely to variable names. It restricts all live binders,
including affine ones.

Beta reduction preserves this antichain condition. A vacuous
contraction only discards its argument and exposes an existing
body. At a live redex `(λu.B) D`, the body `B` contains no other
live binder, and every enclosing binder is vacuous. Substitution
therefore inserts any copies of the live islands in `D` only
beneath vacuous binders. It neither nests them inside a surviving
live binder nor nests them inside each other. Capture avoidance
prevents a vacuous binder from acquiring a new bound occurrence.
Erasing a binder's last occurrence can only remove it from the
live set.

Successful application to `K,R,P` would imply that `H` has a head
normal form. A rigid head cannot produce the required zero head
`R`. A head variable bound by a leading lambda makes that binder
live. Every other surviving live binder would then be inside its
body or, if earlier on the leading lambda chain, would contain it.
Both possibilities violate the preserved antichain. Thus this
head normal form has at most one live binder in its entire syntax.

Every internal redex is consequently vacuous: the only live
binder is on the unapplied leading chain. These internal reductions
terminate by strictly deleting syntax, giving a full beta-normal
form with at most one live binder. The preceding no-`s` obstruction
excludes it. Hence no handler with a live-binder antichain and no
free `s` can satisfy both whole-stream reader laws.

### Two source lambdas without s

An arbitrary no-`s` handler with at most two source lambdas also
fails, with no size or normal-form assumption. The antichain theorem
handles every case except exactly two nested live binders. In that
case, the argument of a source redex cannot contain the other
lambda: the other binder is either an ancestor of the redex or is
inside its body. Contracting any source redex therefore leaves at
most one source lambda, which satisfies the antichain condition and
is excluded. If no source redex exists, the earlier arbitrary-size
floor for beta-normal handlers with at most two lambdas applies.

### Zero, one, or two applications

With `A≤1`, the mandatory rigid leaves `j,c` leave no live
binder or stream occurrence, so all source lambdas are vacuous.
With `A=2`, the third leaf is either an ambient variable, again
giving only vacuous binders, or the sole occurrence of one live
binder with no `s`. Both cases have just been excluded.

### Three applications without free s

There are four leaves. The preceding one-live-binder argument
handles repetitions of the same bound variable and extra rigid
ambient leaves. The only case left has exactly

```
j,c,v,w,
```

with `v,w` bound by distinct live binders. Every source binder
is affine. The normal body head is one of the leading inputs.

If its head is the first input `b`, write the body as
`b A₁ ... A_q`, where `1≤q≤3`. For `q=1`, the variable
branch erases the source of `c`. For `q=2`, zero needs `j`
in `A₁` and variable output needs `c` in `A₂`. Only one
further bound leaf remains. If it lies in `A₂`, the first branch
is a vacuous `j` chain and cannot give head `R`. If it lies in
`A₁`, the second branch is a vacuous `c` chain. Its nonempty
argument suffix ends in `S`, and therefore cannot end in `N`.

For `q=3`, each argument is a lambda chain over one leaf. The
zero branch must contain the other bound leaf, with `j` in the
shared third argument and `c` in the second branch. The variable
branch is consequently a vacuous `c` chain applied to that
`j` chain and any pending external inputs. Its last argument is
either the `j` chain or `S`, never `N`; erasing them all gives
bare `c`. Thus a first-input head fails.

If the head is the second input `r`, `k=2` retains final `P`,
so `k=3`. To give `R j`, its body must have exactly one
argument that reduces to bare `j`.

* If the other live leaf is outer `b`, the base index sum is
  `2+1+4+5=12`. Three lambdas already cost 32 bits, and every
  additional vacuous lambda adds at least three. Only `L=k=3`
  fits, which was excluded earlier.
* If the other live leaf is outer `t`, the base size is 30 bits;
  at most one additional vacuous lambda fits. The sole argument
  is a normal term with one occurrence each of `t,j,c` and two
  applications. A rigid head cannot erase `c`. If its head is
  `t=P`, its callback has either one rigid leaf, or the rigid
  application of `j,c`. With at most one vacuous lambda, the
  callback cannot erase both Scott arguments and the remaining
  rigid leaf. It cannot reduce to bare `j`.
* If the other binder is inside that argument, the argument is
  already beta-normal over `j,c` and its own bound variable.
  The substitution at the outer head `r` does not change it.
  It still contains `c` and is not bare `j`.

Finally suppose the head is the third input `t`, so `k=3`.
The mandatory `j,c` contribute nine index units, giving `L≤5`.
Write the body `t A₁ ... A_q`.

For `q=1`, the callback contains both rigid leaves and the sole
other bound leaf. Its only possible useful head is that bound
leaf. It can receive `K` or `R`, either from the Scott cell or
from an outer leading binder. A `K` head selects a fixed rigid
block and cannot put the later `R` before its `j`; an `R` head
cannot erase the other rigid leaf `c`. Hence zero fails.

For `q=2`, if the sole inner application is in `A₂`, that
argument contains `j,c` and can never become bare `j`.
Otherwise `A₁` has the form of a lambda chain over `w J`,
where `J` is a chain over one rigid leaf and `A₂` contains
the other. The only possible zero output is obtained when
`w=R` and `J=j`. Before exposing that rigid head, the callback
must consume the cell's `K,R` and the common argument `A₂`.
This needs three callback lambdas in addition to the leading
three, contradicting `L≤5`.

For `q=3`, all three arguments are one-leaf chains. To obtain
`R j`, the last must be bare `j` and the other rigid chain
must contain `c`. At most two inner lambdas fit. If the live
leaf is bound inside the first callback, the possibilities are
`I`, `K`, and `F`. Only `I` gives `R j`; `K` gives the
second rigid chain, while `F` leaves two arguments on `R`.
The other zero-compatible possibility is `λa.b`, returning
the outer first input after consuming the Scott bit. A bare
outer `b`, or a chain returning outer `r`, does not give
`R j`. In the two compatible cases, the variable branch is
the `c` chain applied only to `j`. It gives `c j`, bare `c`,
or a remaining lambda, never `c V N`.

This exhausts the no-`s` four-leaf cases.

### Three applications with free s

The only nonvacuous leaf pattern is now exactly `j,c,s,v`,
with one occurrence of a live bound variable `v`. If the normal
body head is a leading input and `k=3`, its base size is at
least 32 bits. Any additional lambda lies above an ambient leaf
and adds at least three bits. Only `L=k=3` can fit, already
excluded. A second-input head with `k=2` retains final `P`.
Thus the remaining bound-head cases have first-input head `b`
and `k=1,2`.

One Boolean argument erases `c` on the variable branch. With
two arguments, the zero branch must contain `s,j`, leaving a
vacuous `c` chain for the variable branch. With three arguments,
the zero branch must be the `s` chain, `j` must be shared, and
the variable branch is again a vacuous `c` chain. In each case
its nonempty final argument suffix ends in `S`, not `N`.

It remains to consider free `s` as the normal body head:

```
H = λ^k.s A₁ ... A_q.
```

For `q=1`, the callback contains `v,j,c` with two applications.
Its useful head must be `v`. The value supplied to `v` can be
`K`, `R`, or `P`. A `K` selects a fixed rigid block; an `R`
cannot erase `c`; and a `P` applied to a rigid or vacuous
rigid callback has that callback's `j/c` head. None gives
`R j`.

For `q=2`, placing the one inner application in `A₂` traps
`j,c` in the same rigid block, which cannot become bare `j`.
Otherwise the first callback is a chain over `v J` and the
other argument contains the other rigid leaf. Only `v=R` and
`J=j` can give `R j`. The callback must then consume all
`6−k` arguments supplied by the Scott cell, the common argument,
and the pending external inputs. Thus `L≥6`; the deeply bound
`j` contributes at least seven index units and `c` at least
two. The wire size is at least `12+12+2+9=35`, beyond the
budget.

For `q=3`, every argument is a one-leaf chain. If `k<3`, the
last ordered input is `P`. Retaining a common `j` application
edge would also retain that final input edge. Consuming all input
edges leaves no fixed source application from which to construct
`R j`: projections and constants return a selected argument
whole. Selecting the final `P` leaves it unapplied. Thus `k=3`.
The case `L=k=3` has already been excluded. For a remaining
candidate the mandatory ambient index sum is twelve, so the
34-bit budget forces `L=4,X=12`. The sole callback is therefore
`I`, with all other arguments bare. The unique zero-compatible
arrangement is

```
λb r t.s I c j.
```

Its variable result is `S I c j→*c j`, not `c V N`.
This excludes the last four-leaf shape.

Consequently no beta-normal `T=s` handler of size at most 34
can have at most three applications. Combined with the compression
results, the same holds for a minimum successful handler: at
`A≤3`, a nonlinear source redex uses both leaves remaining after
`j,c`, so contracting it leaves only vacuous source binders.
Affine redexes are already absent in such a minimum.

## Four applications with four lambdas and two leading lambdas

One further normal `T=s` shape is excluded at 34 bits:

```
A=4,             L=4,             H=λb r.B.
```

The budget gives `X≤8`. Mandatory `j,c` beneath the leading
pair contribute seven index units. A free `s` would contribute
two more and cannot occur. A body headed by `r` would retain
the final zero input `P`, so its head must be `b`. That head's
index one spends the remaining unit.

Consequently `j,c` lie outside both inner lambdas, every inner
bound occurrence has index zero, and every occurrence of outer
`r` lies outside the inner lambdas. Of the five source leaves,
three are already `b,j,c`. The two inner lambdas therefore have
exactly the same closed-block possibilities as in the earlier
one-leading-lambda classification:

```
I,I;       F plus one exterior r;       J=λa.a I;       G=λa d.d d.
```

Substitute the variable inputs `b=F,r=V=Pₘ₋₁`, leaving only
the final `S=Pₘ` pending. The `I/F` cases belong to the base
safe algebra. A functional result contains no `c`, and a rigid
result retains final `S`, so both fail.

The `J/G` cases use both remaining leaves and have no exterior
`r`. For `J`, the internal algebra contains only `F,I,J` and
rigid neutrals. The rules `J U→U I`, `J J→I`, `J F→I`,
`J I→I`, `F J→I`, and `I J→J` close it. Again, its
functional values contain no `c`, and its rigid values retain
final `S`.

For unique `G`, first normalize its context with `G` opaque.
The `F/I` data cannot copy it. If `G` has an internal argument,
its vacuous outer lambda discards that argument and exposes the
unique `Δ=λd.d d`. An internal argument of `Δ` can contain
neither `G` nor another source lambda: it normalizes to `F`,
`I`, or a rigid neutral. The first two give `Δ F→I` and
`Δ I→I`; the last preserves its rigid head and final `S`.
If `Δ` is returned bare, the final input gives `S S→*K N`,
which contains no `c`. If `G` is returned bare instead, its
single final input leaves `Δ`, also without `c`. These cases
exhaust the remaining block.

Thus `(A,L,k)=(4,4,2)` cannot satisfy the whole-stream reader laws.

## Normal four-application handlers without whole-stream access

Suppose `H` is beta-normal, has `A=4`, has size at most 34, and contains no
free `s`. The previous results allow us to assume that `H` has at least
three lambdas, has nonaffine nested live binders, and is neither a three-
leading-lambda handler nor the shape `(A,L,k)=(4,4,2)`.

Its five leaves must therefore be exactly `j,c,u,u,v`, with `u` bound twice
by one binder and `v` bound once by another. Otherwise it is affine, has
only one live binder, or has a live-binder antichain, all already excluded.
If `k` is the number of leading lambdas, a rigid normal body head fails.
There is no stream head available. A second-input head at `k=2` retains
final `P` on the zero branch; a third-input head has `k=3`, already
excluded. Thus its normal form is

```
H = λ^k. b A₁ ... A_q,
```

where `b` is the first leading binder and `q≥1`. All leading-lambda counts
permitted by the size bound remain in scope; in particular `L=5,k=1` is not
discarded.

If `b` is the duplicated binder `u`, substitute the closed affine Boolean
`F` for it. All remaining source binders are affine, including every
inserted copy of `F`. Thus `H′ = λignored. H F` is an affine handler without
free `s`, and

```
H′ F V S =β H F V S.
```

The arbitrary-size affine no-stream theorem uses only the variable law, so
excludes this possibility. No zero law for `H′` is asserted.

Now let `b=v` be affine. The sole other live binder is `u`, used twice. If
`u` is not leading, its binder and both occurrences belong to one of the
arguments `A_i`: a binder enclosing the head `b` would itself be leading.
For `q=1`, the variable Boolean erases `A₁`, including the mandatory `c`, so
this case fails.

For `q≥2`, the zero Boolean selects `A₁` and the variable Boolean selects
`A₂`, followed by the common arguments `A₃,...,A_q` and any unconsumed
external inputs.

* If the `u` island is in `A₁`, the variable branch erases the only
  remaining live binder. Every surviving source lambda is vacuous, and the
  source code contains only rigid `j/c` leaves. A normal term made from
  those leaves and vacuous lambdas, applied to source arguments and the
  remaining external `V,S`, can only erase successive arguments until
  exposing its fixed rigid head. It cannot activate a received argument:
  none of its binders uses that argument. Thus its final rigid spine either
  retains the original last input `S`, or all inputs have been erased and
  only fixed `j/c` syntax remains. Neither gives `c V N`.
* If the `u` island is in `A₂`, the zero branch similarly erases it. The
  surviving normal code consists only of rigid `j/c` and vacuous lambdas. It
  cannot return or activate the later received `R`, so cannot produce head
  `R`.
* If the island is in a common argument, then `q≥3`. Its two `u` leaves need
  at least one application inside that argument. At `A=4`, this forces
  `q=3`; `A₁` and `A₂` each have one leaf, namely `j` and `c` in some order,
  under vacuous lambda chains. The zero-selected `A₁` has a fixed rigid
  `j/c` head and cannot produce `R`. At `q=4`, all arguments have one leaf,
  so the island cannot fit.

It remains that `u` is the second leading binder `r`. Here `k≥2`; the
already excluded three-leading case leaves `k=2`. The mandatory `j,c`
contribute seven index units, so `L≤4`; the existing `(L,k)=(4,2)` result
leaves exactly `L=3`. The third lambda is vacuous. Again `q=1` erases `c` on
the variable branch.

For `q≥3`, zero selects `A₁` and leaves at least two ordered arguments
attached to it, ending in `P`. After substituting rigid `r=R`, the selected
source argument is normal and has only the one possible vacuous lambda. It
can consume at most one of those arguments before exposing a rigid head. A
head `R` therefore still has final argument `P`, and cannot be `R j`.

For `q=2`, zero needs `r,j` in `A₁`; variable output needs `c` in `A₂`. If
both occurrences of `r` were in `A₁`, the variable branch would again be
only a vacuous `c` chain, incapable of `c V N`. Thus the branch leaves are
exactly `r,j` and `r,c`, with one application in each branch. To give zero
output `R j`, the single vacuous lambda must wrap `A₁` and consume final
`P`; otherwise that final edge remains on the rigid output. Consequently
`A₂` is exactly `r c` or `c r`. The variable outputs are respectively

```
c F Pₘ₋₂ S,           c V S
```

for `m≥2`. Neither equals `c V N`.

This exhausts normal no-stream handlers with four applications and size at
most 34.

## Four applications, stream access, and two leading lambdas

Suppose a beta-normal whole-stream handler of size at most 34 bits has
`A=4`, contains `s`, and has exactly two leading lambdas, `H=λb r.B`. The
mandatory j,c,s contribute at least `7+2=9` index units. Since L≥3 and 2L+X≤16,
this forces L=3 and X≤10. There is exactly one inner source lambda D.

A rigid body head fails. A body headed by r retains final P on the zero
branch. Thus the body head is b or s.

If it is b, the index-one head spends the final unit. The occurrences of
j,c,s must all lie outside D, and no outer binder can occur inside D. The
fifth source leaf must therefore be D's own bound leaf, so D=I. There is no
r occurrence. On the variable branch the body is application-only over F,S,I
and rigid j,c, and final S remains pending. The safe algebra excludes the
desired c V N.

Now let the body head be s. On the variable branch substitute b=F,r=V,
leaving final S pending, and abstract the sole inner lambda D by a rigid
marker d. Choose m sufficiently large that every first invocation of d by a
functional Scott value supplies F rather than terminal K, as in the one-
marker index lemma. The syntax outside D is application-only safe data.

If the mandatory c is outside D, an opaque result with functional head or
head d has no way to acquire that outside c as its own head after the final
S is appended unless d has already been invoked internally. An opaque result
headed c retains final S. More directly, if d is invoked internally,
contracting its unique source lambda replaces its bound occurrences by safe
arguments and leaves entirely safe applicative code; if it is never invoked,
the functional or rigid-head alternatives fail, except potentially a bare d
returned to receive the final S. That bare-d alternative can yield c only if
c is inside D.

It therefore suffices to exclude a bare opaque result d when c is inside D.
This placement spends the one index unit remaining after j,c,s, so j is
outside D and b is absent. Every exterior bound occurrence is the leading r
outside D, hence substitutes to V. The opaque context is consequently
application-only over S,V,d,j (and any other rigid leaves), with at least
one occurrence of j.

For this restricted basis, a functional normal form is S, V, I, or Q, with
possible duplicate identical Scott values. Pair/pair interactions return
I,Q, or an N-headed neutral; identity forwards its argument; Q returns N;
and a Scott value applied to a neutral preserves its head and adds two
arguments. In particular, a functional normal form can only come from
subexpressions containing no opaque rigid leaves: in the application table,
every row returning a functional value has functional children. The row I A
forwards a neutral unchanged but its function subtree has no opaque rigid
leaves.

Inductively, a normal form equal to bare d can therefore come only from a
context whose sole opaque rigid leaf is that occurrence of d. Every step
forwarding bare d is an identity step; a Scott invocation adds arguments,
and Q changes its head to N. Since the actual context also contains j, it
cannot return bare d.

Thus D is either lost or trapped under another rigid head, or is invoked
internally with a safe argument. In the last case its body is application-
only, so the result lies in the safe algebra before final S is appended. Its
functional results contain no c and its c-headed results retain final S,
which is not N. This excludes the s-headed case and hence every normal
s-present A4 handler with two leading lambdas at the improving budget.

## Five applications, one leading lambda, and stream access

Suppose a beta-normal handler has five applications, three lambdas, one
leading lambda, at most 34 bits, and a free occurrence of `s`. Write
`H = λb.B`. The variable-stream law would require

```
B[b:=F,s:=P_m] P_(m-1) P_m =β c P_(m-1) N,
```

for every `m≥1`, where `P_0 = cons K N`, `P_(i+1)=cons F P_i`, and
`N` is rigid. The claim below excludes this case using a sufficiently
large `m`.

### Tight syntax inventory

The wire identity gives `X≤6`. The required occurrences of `j,c` have
indices at least 2 and 3 under the leading binder. The required `s`
has index at least 1. They exhaust the index budget. Hence there is
exactly one occurrence of each, all outside the two inner lambdas, and
the other three leaves have index zero. Every inner lambda block is
therefore closed. An index-zero leaf outside the inner blocks is `b`.

With two inner lambdas and at most three leaves, their complete
beta-normal placement inventory is as follows. Omitted leaves are
exterior occurrences of `b`.

* Two separate blocks: `I,I`, or `I,Δ`, where `I=λa.a` and
  `Δ=λa.a a`.
* A nested block with consecutive lambdas: `F=λa d.d`,
  `G₂=λa d.d d`, or `G₃=λa d.d d d`.
* A nested block with the inner lambda as an argument:
  `J=λa.a I`, `Jleft=λa.a a I`, `Jright=λa.a(a I)`,
  `Jmid=λa.a I a`, or `JΔ=λa.a Δ`.

Here application associates to the left. The list follows by distributing
one, two, or three bound leaves among the two lambdas. Consecutive
binders can use only the inner one. In the nonconsecutive case, the
inner block must occur as an argument because the whole term is normal;
with two remaining outer leaves, the three listed placements are all
binary application trees with outer head `a` and one inner-`I` leaf.

### Functional data and opaque helper markers

After substituting `b=F`, treat each not-yet-activated closed block as
an opaque marker. Normalize the surrounding application-only expression
bottom-up using the data algebra. Its functional data values are

```
P_i, F, I, Q=K N,
```

and every other result is headed by a rigid variable or a helper marker.
In particular, no base functional value contains `c`.

The pair/pair cases are important:

```
P_0 P_0             →* Q,
P_0 P_(j+1)         →* I,
P_(i+1) P_0         →* N P_i,
P_(i+1) P_(j+1)     →* P_j P_i.
```

Their recursion decreases `i+j` and ends in `I`, `Q`, or an
`N`-headed neutral. It never returns a Scott cell as its functional
normal form. This recursion may traverse the entire prefix; the
argument does not bound its number of beta steps.

When a functional Scott cell is applied to a helper-headed neutral,
it passes its bit and tail to that helper. We must ensure that this
cell has positive index, so that its passed bit is `F`, not bare `K`.
Without this guard the proof is false: `JΔ P_0 →* K`.

An exposed functional Scott value here means a Scott-valued result that
can still become a function or a first helper argument in this evaluation.
Scott cells or bare `K` values permanently buried in an ordinary rigid
`N`, `j`, or `c` argument spine are excluded: a helper can forward that
whole neutral or apply it to more arguments, but cannot project one of
its arguments. Their indices can be arbitrarily low after pair/pair
cancellation without affecting the guard.

For a finite data phase, regard each already available `P_i`, `F`,
`I`, and `Q` as one macro leaf. If the phase starts with at most `M`
macro applications and all exposed functional Scott leaves have index
at least `h`, every functional Scott normal form obtained in the phase
has index at least `h-M`. This is induction on the application tree:
`P_i F → P_(i-1)` spends an application; identity forwards an existing
value; pair/pair never produces a Scott functional normal form; other
table cases produce no new functional Scott value. The tail exposed
along a helper-headed neutral has the same bound with one additional
unit of margin.

The resulting macro tree has at most `2M` applications. In the table,
the only growth is a Scott cell applied to a neutral, which replaces
one application by two appended spine slots. Bare `K` values buried
in an ordinary rigid neutral never become functional values. The
positive-index guard ensures that they are not instead exposed as
helper arguments.

### Activating the closed helpers

The actions of the possible blocks are

```
I U          → U,
Δ U          → U U,
F U          → I,
G₂ U         → Δ,
G₃ U         → D₃,       D₃ = λd.d d d,
J U          → U I,
Jleft U      → U U I,
Jright U     → U (U I),
Jmid U       → U I U,
JΔ U         → U Δ.
```

Thus an activated helper either discards its input and returns a fixed
closed block, or exposes its input as a function, applied only to
itself or fixed closed blocks. If the input is `c`-headed, the result
is immediately `c`-headed. If it is another rigid neutral, that head
also persists. If it is functional data, all results remain `c`-free.
In particular these helpers never build a functional closure that
retains `c`.

No complex helper can receive an argument containing itself. There is
one occurrence of a complex helper, except for the separate pair
`I,Δ`, and all other initial reducers are affine. Before that helper
is activated, its unique occurrence is neither duplicated nor placed
inside its own argument. In the separate pair, eliminate affine `I`
first. The helper may duplicate a base-data or neutral argument, but
not complex code. `G₂`, `G₃`, and `JΔ` can expose their pre-existing
inner `Δ` or `D₃`; this gives at most two complex activations in all.
The other helper blocks are affine, and their fixed identity outputs
can be included in the base algebra.

For completeness, a uniform prefix guard can be chosen before any
evaluation. Start with `M≤5`. Normalize one data phase, then activate
a complex helper. Its body has at most two applications and uses its
argument at most three times, so the next macro expression has at
most `6M+2` applications. Across at most two such activations, the
successive phase bounds are `5,32,194`. Their total is 231; the
tail-delivery margins and two helper-internal application margins are
less than 10. Taking, for example, `m>600` therefore makes every
Scott cell that supplies a bit to an active helper positive. This
bounds exposed functional-index ancestry, not total data reduction
steps: the unbounded pair/pair cancellation just described is allowed.

After all helpers have been processed, the normal form of
`B[F,P_m]` is therefore either a `c`-free functional value, or a
rigid-headed neutral. Any remaining closed helper value is also
`c`-free and can only be applied to the `c`-free pending arguments.

### The output contradiction

A `c`-free functional normal form cannot acquire head `c` by application
to the two pending `c`-free arguments `P_(m-1),P_m`. A rigid-headed
normal form keeps its head. If the head is `c`, applying those two
pending arguments appends them to its spine. To match the required
two-argument normal form `c P_(m-1) N`, the already normalized body
must be exactly `c`, and the final argument would then be `P_m`, not
`N`. Both are normal and distinct. Every case contradicts the
variable-stream law.

The exclusion uses only the variable law. It applies exactly to the
normal `(A,L,k)=(5,3,1)` shape with free `s`, not to the other normal
five-application placements.

## Five applications and one leading lambda without stream access

Suppose `H=λb.B` is beta-normal, has five applications and three
lambdas, and contains no free `s`. The wire identity gives `X≤6`.
Mandatory `j,c` already contribute `2+3=5` under the leading binder.
Thus each occurs once, at most one can lie under one further lambda,
and only one other positive index unit is available.

A rigid body head cannot satisfy the zero law. Hence

```
B = b A₁ ... A_q,       q≥1.
```

For `q=1`, the variable input `F` erases all source arguments, including
`c`, so this fails. For `q≥2`, `K` selects `A₁` and `F` selects `A₂`,
followed by the common arguments `A₃,...,A_q` and the two external
arguments `R,P` or `V,S`.

### Only three nonlinear leaf patterns remain

If both inner binders are affine, the source term
`λignored.B[b:=F]` is an affine handler without free `s` and satisfies
the required variable law. The already established arbitrary-size affine
no-stream theorem excludes it. Thus an inner binder `u` must occur at
least twice. It is nonleading, so its binder and all its bound occurrences
belong to one argument `A_i`.

There are only six leaves, including mandatory `j,c`, the head `b`, and
two `u` leaves. The remaining leaf is exactly one of:

* another `b`, with the other inner lambda vacuous;
* a third `u`, with the other inner lambda vacuous;
* one occurrence `v` of the other inner binder.

Another rigid ambient leaf or a repeated `j/c` would exceed the index
budget. Both inner binders cannot be nonlinear because that would need
at least seven leaves including the head and `j,c`.

### A selected branch containing u

If the `u` island lies in `A₁`, the variable selector erases it. The
surviving variable branch is affine, even if the source had another
occurrence of `b`, because all surviving `b` occurrences are closed
copies of affine `F`. The affine no-stream variable-law theorem again
excludes it.

If the `u` island lies in `A₂`, the zero selector erases it. In the
extra-`b` or extra-`u` leaf patterns, every remaining source binder is
vacuous; only `K` selectors and vacuous erasers remain. The ordered-input
argument already used for one live first-input binder excludes `R j`:
selectors forward arguments whole and erasers discard them, but neither
can insert a later received rigid `R` into a fixed source application
with the earlier `j`. Exposing `R` before the last input is consumed
retains final `P`; exposing or returning `P` after that input edge is
consumed leaves no later argument with which to activate it.

In the extra-`v` pattern, `b` occurs only once. After zero selects `A₁`,
there is no internal Boolean `K` and no `s` occurrence in the remaining
source. At most one source lambda remains, the affine `v` binder.
All other source terms before the external `R,P` are rigid expressions.
If that lambda is internally activated, it consumes a rigid source
argument and leaves no source lambda. If it is reached as a bare
function, its first supplied argument is either such a rigid source
argument or `R`; it cannot first receive `P` while the earlier `R`
input is still pending. In either case an exposed `R` still has final
`P` attached. Thus this zero branch cannot be `R j` either.

### A shared argument containing u

It remains that the `u` island is in `A_i` for `i≥3`. Its two bound
leaves require an internal application, so `q≤4`.

#### Four head arguments

For `q=4`, the one remaining application is inside the `u` island.
That argument has exactly its two `u` leaves; the other three arguments
are one-leaf chains over `j,c` and the extra `b` or `v`. A third `u`
cannot fit. The `u` island has no rigid `j/c` leaf.

Zero correctness rules out `A₁` being a chain over `j` or `c`: such
a vacuous chain can only expose its fixed rigid head. Hence `A₁` is
the `b` or `v` chain. Variable correctness then rules out a `j` chain
as `A₂`, so `A₂` must be the `c` chain. After selection, it receives
four ordered arguments, `A₃,A₄,V,S`. The `u` binder is in a shared
argument, so at most the other inner lambda can wrap this `c` chain.
It can erase at most one of the four arguments before exposing `c`.
At least three arguments remain on the rigid output, whereas the target
`c V N` has exactly two. This excludes `q=4`.

#### Three head arguments

For `q=3`, the shared `u` island is `A₃`. There are exactly two
applications inside the three arguments.

If `A₃` has three leaves, it uses both applications, and `A₁,A₂`
are one-leaf chains. Its third leaf is one of `u,b,v,j,c`.

* If it is `u,b`, or `v`, both rigid leaves are in the selected
  one-leaf branches. The zero-selected branch has a fixed rigid head
  and cannot produce `R`.
* If it is `j`, the remaining branches have `c` and `b` or `v`.
  Zero correctness forces the nonrigid branch to be `A₁`, leaving
  `A₂=c`. The `j` inside the `u` island spends the only extra index
  unit, so `c` is under no inner lambda. Variable selection therefore
  produces `c A₃ V S`, with three arguments rather than two.
* If it is `c`, the analogous head requirement for the variable branch
  forces the nonrigid branch to be `A₂`, leaving `A₁=j` with no
  inner lambda, so the zero branch has the wrong head.

If `A₃` has exactly its two `u` leaves, it uses one application.
One selected branch therefore has two leaves and the other has one.
Since `j` must survive zero and `c` must survive the variable branch,
`j` belongs to `A₁` and `c` to `A₂`.

In the extra-`v` pattern, the branch containing `v` also contains its
sole live binder. If it is `A₂`, the zero-selected `A₁` is bare `j`
and fails. If it is `A₁`, all inner lambdas are already in `A₁,A₃`,
so `A₂` is bare `c`, and variable output is `c A₃ V S`, again
with three arguments.

In the extra-`b` pattern, a one-leaf zero branch over `j` fails. Thus
`A₁` contains `b,j` and `A₂` contains `c`. A `j`-headed application
cannot give head `R`, leaving only `A₁=b J`, where `J` is `j` or a
vacuous chain over `j`. Zero selects `K J`; applying shared `A₃`
returns `J`, after which only `R,P` remain. It has fixed head `j`,
so cannot give `R j`. A vacuous lambda around all of `b J` would
raise both the `b` and `j` indices, spending two units when only one
is available. Wrapping its head alone would be a source beta redex,
contrary to normality. These cover placements affecting `A₁`; a
lambda outside `A₁`, including in `A₂` or around the `u` island,
cannot change this zero computation. The extra-`u` pattern cannot have only two `u` leaves
inside its unique binding island.

This exhausts the common-argument cases and therefore excludes the
normal `(A,L,k)=(5,3,1)` shape without free `s`.

## Five lambdas and one leading lambda with stream access

Let a beta-normal whole-stream handler have `A=4, L=5`, exactly one leading lambda,
and size at most 34 bits. Suppose it contains `s`. Write `H=λb.B`. The wire
budget is `X≤6`. Mandatory `j,c,s` under `b` contribute exactly `2+3+1=6`, so they
occur exactly once, all outside the four inner lambdas. Every other leaf has
index zero. Every inner lambda block is therefore closed; an index-zero
occurrence outside those blocks is b.

There are only two bound leaves in all. Write F_h=λ a1...ah.ah for the
h-argument last projection, with F₁=I and F₂=F. The complete normal block
inventory is:

* One block F₄, and one exterior b leaf.
* Two separate blocks F_h,F_l, with h+l=4.
* One consecutive block λ a b c d.d d, namely three vacuous lambdas followed by
  Δ=λ d.d d.
* One nonconsecutive block J_(h,l)=λ a1...ah.ah F_l, with h+l=4 and h,l≥1.

To see completeness, with one leaf all lambdas form a last-projection chain. With
two leaves in separate blocks each is such a chain. With two leaves in one
block, either both refer to the innermost binder on one consecutive chain,
or the inner block is an argument to the outer bound head. Normality
excludes an inner lambda in function position, and index zero excludes capturing
an outer binder inside the inner block. There is exactly one inner
application in either of these two-leaf single-block cases.

Substitute b=F and s=Pₘ. Extend the safe functional algebra by all last
projections F_h. Their application rules are

    F₁ U =β U,
    F_(h+1) U =β F_h,
    P_i F₁ =β I (i>0), or Q (i=0),
    P_i F₂ =β tail_i,
    P_i F_(h+2) =β F_h  (h≥1).

Together with the original safe table, these rules close the application-
only algebra over P_i,Q,F_h and rigid neutrals. A functional result contains
no c; applying a functional Scott cell to a neutral preserves the neutral
head. No bare K is introduced, even at i=0.

For either of the two-leaf single-block cases, both bound leaves are inside
that block. There is no exterior b and no other source lambda block. The normal
exterior therefore contains only the sole s, this block D, and rigid j,c.
Its head must be s. If its first callback is rigid-headed, that rigid head
receives the Scott bit and tail and later the external V,S, so fails.
Otherwise its first callback is the literal block D: source normality
excludes applying D in the callback's own syntax. Thus the only potentially
successful activation starts with S D.

For J_(h,l), h+l=4, the three possibilities on S=Pₘ, m≥1, are

    S J_(1,3) =β V,
    S J_(2,2) =β V F =β tail_(m-1),
    S J_(3,1) =β J_(1,1) = λ z.z I.

The first two are safe data, and the last receives only rigid j/c source
arguments before the pending V,S. It either remains a closed c-free helper
or preserves the head of the rigid argument on which it is activated. These
computations also explain why no terminal-K assumption is hidden: if the
initial stream were P₀, the h=1 callback gives K F_l N =β F_l; h≥2 discards
the terminal K in a vacuous binder.

For D=λ a b c.Δ, its first two vacuous binders discard the stream bit and
tail:

    S D =β λ c.Δ.

The sole internal Scott source has now disappeared. There is no exterior b
or other block. Before the pending V,S, the remaining arguments are made
only from rigid j,c. Consequently the result is either a closed c-free
remainder of D/Δ, or a rigid-headed neutral. In particular bare Δ cannot be
re-invoked as a Scott callback internally. This point is necessary: P₀ Δ =β
K would not be safe in an unrestricted helper algebra.

Thus the fully processed body B[F,Pₘ] is either a c-free functional value or
a rigid neutral. Appending the two pending c-free arguments V=Pₘ₋₁ and S=Pₘ
cannot create c in the functional case. In the rigid case, head c retains
both arguments; equality with c V N would require the body to be bare c and
S=N, which is false. This excludes the variable law and hence every such
A4,L5,k1 handler.

## A unique stream occurrence and at most one live binder

Let `H` be beta-normal and nonleading, contain exactly one occurrence of
`s`, and have at most one live source binder. Its multiplicity is
unrestricted; every other source binder is vacuous. The mandatory rigid
names `j,c` may occur more than once. If it satisfies the zero law, then

```
L ≥ q+4,             2L+X ≥ 3q+15 ≥ 18,
```

where `q≥1` is the number of arguments on its outer `s` spine.

A rigid head fails the zero law, so write `H=s A₁ ... A_q`. The first
callback `A₁` has no `s` and no free source-bound variable. If it is
application-headed, its normal head is rigid and `P A₁` preserves that
head. It must therefore be a leading lambda block `D`. Its normal body
head must be the unique live binder `u`; with no live binder, a fixed
rigid body head fails immediately. Thus `u` lies on `D`'s leading chain.
Let `d` be the length of that chain.

After expanding the zero cell `P=cons K R`, `D` receives the ordered list

```
K,R,A₂,...,A_q,K,R,P.
```

It has `n=q+4≥5` entries. Consider the argument received by `u`.

If it is a common source argument `A_i`, that argument contains only
rigid ambient names and vacuous lambdas: `u`'s binding scope is inside
`A₁`, and the unique `s` has already been used at the outer head. Such a
normal argument can only discard arguments before exposing a fixed
rigid head, or remain a lambda if insufficiently applied. Its copies
cannot yield head `R`.

If `u` receives `K`, all earlier leading binders were vacuous, so any
earlier direct `R` was discarded. After substituting `K` for every
`u` occurrence, only selectors and vacuous erasers remain. Vacuous
wrappers may still contain fixed `K` and `j`; they do not capture a
received argument. The ordered-input argument from the one-live
first-input case applies: selectors return an argument whole and
vacuous binders discard it; neither inserts a later received `R` into a
fixed source application with the earlier `j`. Exposing `R` before the
last input is consumed retains final `P`. Selecting final `P` only after
earlier input edges have disappeared leaves it with no later argument.
Neither case yields `R j`.

If `u` receives a direct `R`, substituting this rigid value creates no
redex in `D`'s normal body. Once its `d` leading binders have been
consumed, the rigid head retains every remaining ordered argument.
Thus zero correctness requires `d≥n`, so that final `P` has already
been consumed. If `u` receives final `P` itself, its position on the
leading chain likewise requires `d≥n`.

In either last case, every common argument containing a `j` has been
discarded by a vacuous binder: the only live binder receives `R` or `P`.
Consequently a surviving `j` must occur inside `D`'s body beneath all
`d` leading lambdas. Its index contributes at least `d+1`, and mandatory
`c` contributes at least two. Since `L≥d`,

```
2L+X ≥ 2d+(d+1)+2 = 3d+3 ≥ 3q+15.
```

This proves the stated bounds. In particular `L≤4` is impossible
regardless of the application count.

For an improving four-application handler, the budget is `2L+X≤16`,
so every unique-`s` case with at most one live binder is excluded. In
particular a nonlinear nonleading `A=4` handler has exactly the leaves
`j,c,s,u,u` and falls under this result. Every remaining nonleading
normal `A=4` handler is affine with at most two live binders.

For an improving five-application handler, `2L+X≤12`, so the same
unique-`s` cases are excluded. A remaining nonlinear nonleading `A=5`
handler therefore has exactly one of the leaf allocations

```
j,c,s,u,u,s,             j,c,s,u,u,v,
```

where `v` is the sole occurrence of a distinct affine binder in the
second allocation.

## Affine nonleading four-application handlers with a single outer callback

Suppose H is beta-normal and affine, A=4, |H|<=34, and H=s D with exactly one outer head argument. Suppose the leaves are exactly s,j,c,u,v, with u,v distinct live binders. (The unique-s cases with at most one live binder are already covered by the ordered-input lemma.) Both live binders and all source lambdas lie inside D. Its four leaves are u,v,j,c and it has three applications.

Write D=lambda^d.w B1...Bp. Its normal head w must be one of its leading bound variables; a rigid head cannot produce zero head R. Mandatory j,c lie under all d leading lambdas, so X>=2d+3. Since L>=d and 2L+X<=16, d<=3. The zero activation supplies D with

    K,R,K,R,P.

A leading head bound to R would expose rigid R while final P remains, because d<=3<5. No leading binder can yet receive P. Thus the head receives K, from input one or three. The internal head arity p is one, two, or three.

We use one small zero-law fact. A beta-normal source containing mandatory j,c, no s, and exactly one affine live binder cannot produce R j when supplied K,R,P, or R,P. Its head must be that live binder. A K value leaves only selectors and vacuous erasers and fails the ordered-input argument. A rigid R substitution creates no redex in the source normal body, which still contains c if all pending inputs are consumed, and retains final P otherwise. If the binder receives final P, this is the sole occurrence of P. Its callback contains only rigid j/c and vacuous lambdas, so P applied to that callback has a fixed j/c head, never R. These cases exhaust the possible received arguments.

### One or two leading callback lambdas

For d=1 the K-valued head is the first binder. For d=2 it is again the first binder, and the second live binder is either the leading R binder or lies inside an argument.

If p=1, the head is K B1. For d=1, the next supplied R is discarded, leaving B1 K R P. For d=2, the next supplied K is discarded, leaving B1 R P. All remaining source leaves are the other bound leaf,j,c. If that bound leaf is bound inside B1, the preceding one-affine-binder fact applies. If it is the leading R binder at d=2, substituting rigid R preserves B1's normal form, including mandatory c; vacuous lambdas can only discard the pending arguments. It cannot give R j.

If p=2, K selects B1 and discards B2. Zero correctness forces the other bound leaf and j to be in B1 and c in B2: without the bound leaf B1 has only a fixed rigid head; j cannot be discarded. Each branch then has respectively two leaves and one leaf, so B1 has exactly one application. A j-headed branch fails. If the bound head v receives K, its sole source argument is a fixed j chain, so selection exposes that fixed head rather than R. If v receives final P, it invokes that rigid or vacuous j callback, again yielding head j. Thus only v=R can succeed. Its argument must then be bare j: a vacuous lambda around j would remain under the rigid R. The only useful form is consequently a lambda chain over v j, with v either an inner bound variable receiving R or the already supplied R. The selected branch receives four pending inputs for d=1, or three for d=2, ending in P. All must be consumed before rigid R is exposed, and j must be bare. Thus j lies below at least five source lambdas in total, and L>=5. The c leaf is beneath at least the d leading lambdas of D. In particular X>=6+3=9 and 2L+X>=19>16. This is impossible.

If p=3, all B1,B2,B3 are one-leaf lambda chains over the other bound leaf,j,c. A selected j/c chain has the wrong head. The only alternative is a chain projecting the other bound leaf, with j in B3 and c in B2. It is applied first to B3 and then to the remaining ordered inputs ending P. Such a one-leaf chain only discards arguments or returns one whole: it contains no fixed application that could attach the earlier j to the later R after final P has been consumed. Returning R earlier retains final P; returning it after all inputs gives bare R; returning j or final P also fails. Thus p=3 is impossible.

### Three leading callback lambdas

For d=3, the mandatory j,c already give X>=9. The budget forces L=3, so there are no inner source lambdas. The second live leaf is either R or another K. If it is another K, only selectors and vacuous erasers remain; the ordered-input argument excludes R j with pending R,P.

If it is R, the application-only body has exactly one occurrence each of K,R,j,c. Its functional normal form can contain at most one constant lambda, of the form K A: there is only one K occurrence, and all other leaves are rigid. A rigid result retains final P. A one-constant result applied to R,P exposes A and still applies P to it; A is rigid because no K remains inside A. A bare K, even if returned, gives R after these inputs, not R j. Thus the body cannot absorb both pending inputs and return R j.

This exhausts the d<=3 possibilities. Hence no affine, nonleading normal A4 handler H=s D with unique s fits the improving budget.

## Nonleading five-application handlers with four or five outer arguments

Suppose a beta-normal
handler has no leading lambda, has five applications and at most four
source lambdas, and satisfies the zero law. Its normal head must be `s`,
so write

```
H = s A₁ ... A_q,
P = cons K R,
H[P/s] K R P =β R j.
```

Here `R,j` are distinct fresh rigid variables. The claim is that `q≤3`.
This covers both remaining normal A5 lambda counts at the 34-bit budget.

### Where the output application can come from

Use an ordinary weak-head trace to the rigid head of the required normal
form, then normalize its arguments. Label application constructors by their
source. A beta step deletes its contracted application and copies the
application constructors already in the lambda body or its substituted
argument; it does not create an application constructor of a new origin.

The zero input data has only the Scott body `h K R` and projection
body of `K`. Every application in a Scott body has fixed right argument
`K` or `R`. Those right arguments cannot normalize to `j`. Projection
or eraser lambda chains have no applications in their bodies. Consequently
the final application `R j` must come from a source application of `H`.

An application on the original root spine of `H` is followed by the
three external argument edges carrying `K,R,P`. During head reduction,
that original edge stays on the pending global spine until it is consumed.
Its constructor is never placed in an argument: the pending root edges
are consumed in order, while substitution moves their argument subterms,
not the enclosing pending application constructors. If such an edge
survived as `R j`, the later external `P` edge would still be appended.
If it is consumed, that constructor is gone. Thus the target `R j`
cannot originate on the root spine.

### Five outer arguments

For `q=5`, all five applications lie on the root spine. Every `A_i`
is a lambda chain over one leaf. There is no remaining source application
that can become the target `R j`, so the zero law fails.

### Four outer arguments

For `q=4`, exactly one source application lies inside an `A_i`. It
must supply the final `R j` constructor. Its function child is a bare
variable because the source is beta-normal and this is the only inner
application. Its argument child must also be a bare variable: an enclosing
lambda on that right child could not disappear while this same application
constructor survives under the final rigid head `R`.

The function leaf cannot be a rigid ambient variable, and it cannot be
free `s`: substituting `P` would make this application itself a beta
redex and consume its constructor. It must be a bound variable `u`
whose supplied value becomes bare `R` without consuming this application.
The right leaf must become `j`. In particular the two leaves cannot be
the same bound variable: confluence would then make the same supplied
term equal to the distinct normal rigid variables `R` and `j`.

Call the lambda chain enclosing this unique application `D`. It has at
least one lambda. Its only body application is `u j` or `u v`, and
every other source block is a one-leaf projection/eraser chain. There is
no other nonlinear source code that could copy `D` before it is used;
the input data is affine as well.

#### D is the first callback

If `D=A₁`, expanding the zero stream gives it the ordered inputs

```
K,R,A₂,A₃,A₄,K,R,P.
```

It has at most four leading lambdas. If its function variable `u`
receives the first `K`, the distinguished inner application is consumed.
If it receives the second input `R`, exposing its rigid body still leaves
the final `P` pending. If it receives `A₂` or `A₃`, that source
argument is a beta-normal one-leaf chain: it is a lambda, a rigid ambient
variable, or literal `P`, never bare `R`. A lambda consumes the
distinguished application; a rigid head is wrong. No later input can yet
reach `u`. Thus this case fails.

#### D is a later argument

Now `A₁` is a one-leaf chain with at most three lambdas, because `D`
uses at least one of the at most four source lambdas. Its leaf is one of
its bound inputs, free `s`, or a rigid ambient variable. The following
cases exhaust its head behavior. A rigid result cannot give `R j`.

With no lambda, the only possible functional leaf is `P`.
`P P → K R`, and the next argument is discarded before exposing `R`
with final `P` still pending.

With one lambda, the only relevant cases are `I` or a constant chain
returning `P`. They give respectively `P I → K R` and
`(λ_.P) K R → P R → R K R`. Both expose `R` too early.

With two lambdas, the projections are `K` and `F`, and the remaining
functional possibility is a constant chain returning `P`.

* `F` exposes the first tail `R` too early.
* `K` leaves the state `A₂ A₄ K R P`. If `A₂=D`, then `D`
  has at most two lambdas and receives only `A₄,K`; neither can supply
  a bare `R` while preserving the distinguished application. If `A₂`
  is another source chain, it has at most one lambda. Identity forwards
  `A₄`, whose only possible `D` then receives `K`. A constant
  returning `P` gives `P K R P → R`. If `A₂` is literal `P`,
  it invokes `A₄`: a `D` there has at most two lambdas and receives
  `K,R`, after which `K,R,P` still remain; another literal `P`
  exposes `R` too early. All rigid cases fail.
* A constant chain returning `P` leaves
  `P A₂ A₃ A₄ K R P`. A `D` in `A₂` has at most two lambdas,
  receives `K,R`, and still leaves the final `P`. Any other source
  chain in `A₂` has at most one lambda: identity, constant `P`,
  literal `P`, and rigid cases reduce exactly as in the preceding
  one-lambda cases, exposing `R` early or a wrong rigid head.

With three lambdas, no other source chain can have a lambda except the
single lambda of `D`.

* Selecting the first input returns `K`, which selects `A₃` and
  leaves `A₃ K R P`. A `D` there receives `K`; literal `P`
  gives `P K R P → R`; rigid cases fail.
* Selecting the second input exposes `R` too early.
* Selecting the third input leaves `A₂ A₃ A₄ K R P`. A `D`
  in `A₂` receives the normal source argument `A₃`, never bare
  `R`. If `A₂` is literal `P`, a `D` in `A₃` receives `K`,
  while another literal `P` exposes `R` too early. Rigid cases fail.
* A constant chain returning `P` leaves `P A₃ A₄ K R P`.
  A `D` in `A₃` receives `K`; a literal `P` exposes `R` too
  early; and a rigid callback has the wrong head.

In all cases a supplied value that is a lambda consumes the distinguished
application itself, so cannot be an unmentioned way for that constructor
to survive as `R j`. The cases above exhaust the at-most-three-lambda
prefix before `D` and show that it never receives a bare `R` and then
consumes the final `P` before exposing its body. This excludes `q=4`.

Therefore every remaining nonleading normal A5 handler at the improving
budget has at most three outer arguments.

## One index-tax unit cannot absorb the three external inputs

The following handwritten argument has been independently reviewed. It
excludes every affine handler with `X≤4`, regardless of its lambda count,
and also the remaining nonlinear `A=5,L=4` allocations. Those allocations
have exactly one binary binder `u` and are

```
j,c,s,u,u,s,             j,c,s,u,u,v.
```

Every other binder is affine. The proof tracks which lambda constructors
can contain `c` in their bodies when they are contracted.

### The positive-tax inventory

The mandatory ambient leaves `j,c` contribute at least `1+2=3` to `X`.
Every remaining index contribution is a crossing through a source lambda
whose binder does not bind that occurrence. Thus there is at most one
positive-tax source lambda `Z`, with tax one. Every zero-tax source lambda
is a closed whole subterm: all leaves in its body are bound by itself or
by an inner lambda, including any references to outer source binders in
this closedness test. The initial `c` is unique, since a second occurrence
would already give ambient index sum at least five. A second `j` spends
the last unit and leaves no positive-tax lambda at all.

Use the outermost opaque-source-block normalization strategy. A lambda
body remains opaque until its enclosing binder is activated. Every
zero-tax lambda and every copy of it therefore stays closed while present:
substitution outside a closed subterm does not change it. When it is
applied, its constructor is consumed before its argument enters the body.
It cannot be contracted with `c` already in its function body.

Only `Z` can contain `c` at contraction, either initially or after
substitution for its one free bound-variable occurrence. In the affine
case, `Z` is never copied, so at most one source contraction can have this
property.

In the binary case write `U=λu.B`. Before its first activation, every
other reduction is affine, so its sole occurrence is never copied. Its
argument cannot contain `U` itself: the unique occurrence is the function
being contracted, and finite term syntax cannot contain that same
occurrence also in its argument. Moreover every enclosing source binder
has already been consumed by the outermost strategy. Its contraction
therefore cannot duplicate an occurrence bound by an intact enclosing
affine binder and make that binder nonlinear.

After `U` contracts, all remaining source binders are affine. Thus `U`
fires at most once and copies its argument at most twice. The constructor
`Z` has at most two copies over the whole strategy: if already activated,
it is gone; if in `U`'s argument it is copied at most twice; if in `U`'s
body it is not copied. If `Z=U`, it has only its original activation.
Consequently at most two source-lambda contractions have `c` in their
function bodies. This counts all copies of `c`, not just a selected one.
Copying `c` elsewhere cannot turn a closed lambda into a lambda containing
`c` while that constructor remains intact.

### Safe data cannot add a lambda that captures c

Choose a sufficiently long prefix using the established functional-index
ancestry guard, counting the three final applications in the starting
macro syntax. In the affine case, with `A` source applications and `L`
source lambdas, `m>2^(L+1)(A+5)` suffices. The argument uses the finite
number of source activations; it does not require the pending-argument
inequality `n≥L+1`.

In the binary four-lambda case, `U` can add at most three source-lambda
copies. There are at most seven source activations and eight opaque
data-normalization phases. Each phase at most doubles the macro
application count, and `U` at most doubles it once more. The conservative
choice `m>2^10(A+5)` dominates the exposed-offset and tail-supply bounds.

The guard prevents a source callback from receiving bare terminal `K`.
It bounds exposed functional Scott offsets, not total beta steps: a
pair/pair calculation can traverse the prefix but returns `I,Q` or a
rigid neutral, never an exposed terminal callback.

The safe atoms `F,I,Q` and Scott cells have no surviving inner lambda
that captures a supplied argument containing `c`. The only exception in
the finite input representation would be the inner lambda of bare `K`.
The data algebra never returns bare `K` functionally, and the guard
excludes a terminal callback supplying it to a source block. A `K` inside
a rigid neutral stays trapped; pair/pair uses apply it only to data
without `c`. Hence no data-lambda contraction in this strategy has `c`
in its function body.

Across source and data alike, at most one contraction in the affine case,
or two in the binary case, can contract a lambda whose body contains `c`.

### Three original root applications require three such contractions

Tag the three original root-spine applications carrying
`F,V=Pₘ₋₁,S=Pₘ`. Their right subterms contain no `c` and remain so.
At least one source occurrence of `c` must survive to the required
normal form `c V N`.

The final original application to `S` must contract: otherwise its normal
right argument remains the final argument `S`, which is not
beta-equivalent to `N`. Its function can become a lambda only after the
preceding original application to `V` contracts. That contraction in turn
requires the preceding original application to `F` to contract. An
uncontracted application remains an application at the root of its own
subterm and cannot itself become a lambda.

At each of these three contractions, a surviving `c` lies in the function
lambda's body. The original right data argument has no `c`, and erasing
every `c` on this root spine could not yield the target. Thus the three
distinct original application constructors require three contractions
whose lambda bodies contain `c`. This contradicts both upper bounds.

Therefore all affine `X≤4` handlers and both remaining nonlinear
`A=5,L=4,X≤4` allocations are excluded. Together with the preceding
three-lambda and compression arguments, **no improving whole-stream
handler has five applications**. The affine result also excludes
nonleading `A=4,L≥6` candidates, since their wire budget gives
`X≤16−2L≤4`.


## Affine four-application handlers with a unique stream and several arguments

Let H be normal and nonleading, with A=4, a unique s,
and the other four leaves j,c,u,v for distinct affine live binders.
Assume 2L+X<=16. The affine floor gives L>=4. The affine X<=4 obstruction excludes
L>=6 at this budget, so only L=4 or L=5 remains.
Write H=s D A2...Aq, q>=2. Expand the initial zero cell to obtain

    D K R A2...Aq K R P,       n=q+4 original input edges.

The established ordered-input invariant applies unchanged with final P:
all n input edges must disappear, and the final Rj application comes
from one of the 4-q fixed source applications inside the arguments.
The first callback D must have a lambda and a bound body head. There is
no other free s in any argument.

### Four arguments

If q=4 there is no fixed source application, so Rj has no possible origin.

### The source-head path with two live occurrences

We use the same two-live-occurrence accounting as in the 30-bit proof.
Only a source live occurrence can move a supplied R into a fixed source
application. A supplied K can select a source block; its two contractions
consume at most two original input edges. There can be at most one useful
such K before the final R-producing occurrence. Thus L>=n-2=q+2.

Here L<=5<n. Therefore some original input edge must be consumed by
a useful K. The other live occurrence cannot merely import the target
j: inserting both R and an imported j into the fixed target application
would already use both live occurrences and leave no useful K. Thus j
is a literal leaf of the final useful source block.

Nor can the final live occurrence receive final P. The other occurrence
has already been consumed as the useful K. The fixed callback supplied
to P therefore contains only vacuous source lambdas and j/c leaves. It
can discard K,R or expose its fixed j/c head, but cannot return an R
head. If the other live occurrence instead remained inside that callback
or was held as a not-yet-used K/R value, there would be no useful K before
P was received; all n original input edges would need source contractions,
contrary to L<n.

Consequently the successful path would use an R-valued live occurrence
with its surviving literal j in the same source block. The other live
occurrence provides the required useful K.

### Both live occurrences in D

If both occurrences lie in D, the useful K must select a fixed source
block containing the surviving j and the final R occurrence. If K instead
selects an original input argument whole, it loses that D subterm. Thus
at least one K contraction is spent on its fixed selected argument, and
K consumes at most one original input edge. All other input edges require
source lambdas.

Every source lambda on this successful path is above the surviving j:
before the K they are in D's leading chain, and afterwards they are in
its selected fixed subblock. Hence j has depth at least n-1>=5 and
L>=5. Since j,c have base index contribution three,

    2L+X >= 2*5 + (5+3) = 18 > 16.

If no K is used, the same argument gives the stronger depth n.

### The final R occurrence is in a later argument

The D block contains only the first live occurrence. If it also contained
c, its normal body could only apply its head to a fixed c-containing
block: a K head selects that wrong fixed head, while a forwarded callback
would spend a source contraction on the fixed c argument in addition to
all original input edges. The latter has no useful K and already needs
L>=n>5. A rigid R head fails immediately. Thus D is a one-leaf
projection chain, and c is in one of the later source arguments.

For q=2, both j,c lie in A2. A projection merely forwarding A2 uses
its only live occurrence for that forwarding, leaving no useful K before
the final R occurrence; L<n already excludes every such forwarding depth.
The only useful-K route is for D to consume K,R and return the first K,
selecting A2 and discarding the external K, leaving A2 R P. Returning
the first K sooner selects R and loses A2. Returning it later has already
discarded A2; a returned R is rigid. The A2 block has one affine live
occurrence, only rigid j/c otherwise, and no s. The one-live zero-law fact
proved in the single-callback section excludes this residual R,P list,
regardless of its vacuous lambdas.

For q=3, exactly one fixed source application remains, so the selected
argument is a lambda chain over v j, while c lies in the other argument.
A projection that merely forwards the selected argument uses no useful K
and needs n=7 source lambdas, impossible. The useful K therefore comes
from D. There are just two ways to select an argument containing j:

    D=lambda a b.a,       selected A2 receives K,R,P;
    D=lambda a b x.a,     selected A3 receives R,P.

An earlier return selects rigid R; a later return has discarded every
common argument containing j. In the first row the selected block must
be lambda b r t.r j; in the second it must be lambda r t.r j.
Its R occurrence must be followed by a vacuous lambda consuming final P.
The fixed target application precludes a lambda around its j argument.
Both rows require five source lambdas along the path and have index tax

    X >= 8:
    first row: j=4, c>=2, D's a=1, selected r=1;
    second row: j=3, c>=2, D's a=2, selected r=1.

Additional unused lambdas only increase L or X. Thus 2L+X>=18, again
outside the budget.

This excludes q=2,3,4 and completes the unique-s/two-affine-live-leaf
nonleading A4 case. The affine X<=4 obstruction is used only to reduce
L to four or five.

## Normal four-application handlers with one leading lambda and bound body head

Let H be beta-normal in frame [s,j,c,p,x], have A=4,
L=3 or4, exactly one leading lambda, mandatory j,c and at least one s,
and size at most34. Suppose H=lambda b.B and the normal body head is b.
Then H cannot satisfy both whole-stream reader laws.

Write B=b A1...Aq, 1<=q<=4. There are five source leaves: the head b,
j,c,s, and one additional leaf a. The latter may be a second b, a leaf
bound by an inner lambda, or any ambient variable. All inner binders
except possibly the one binding a are vacuous. At zero put s=P=cons K R;
at a sufficiently long variable put s=S=P_m and V=P_(m-1).

### One or four body arguments

For q=1 the variable reduct is F A1 V S -> V S, with no c, so fails.

For q=4 every source application lies on the body root spine. None can
become the final R j constructor: until consumed it stays on the pending
root spine before the final external P edge, and consuming it deletes its
constructor. Zero-input data applications have fixed right argument K or
R, so none can supply the j argument. All source arguments are one-leaf
lambda chains with no application constructors. Thus the zero law fails.

### Three body arguments

There is exactly one inner source application. As above it must become
final R j. Its right child must be bare j: a lambda there would survive
under rigid R. Its function child is a variable, since a lambda there
would violate source normality. A rigid ambient variable has the wrong
head; s specializes to P and would consume the distinguished constructor;
b specializes to K and would do the same. Consequently its function is
the additional leaf a, bound by an inner lambda, and its value must become
bare R without consuming that constructor.

Let D be the lambda chain containing this sole application a j. It has
d>=1 lambdas. The two other arguments are vacuous lambda chains over c
and s. D cannot be A2, which is erased on zero together with j.

If D=A1, its ordered zero inputs are A3,R,P. A3 is a normal one-leaf
chain over c or s, never bare R. Receiving P would consume the distinguished
application. Thus a must receive R, and all three inputs must be consumed
before the rigid R is exposed. This forces d>=3. Together with the outer
b lambda, L>=4 and j has index contribution at least5. The c and s leaves
under b contribute at least3 and1. Hence X>=9, whereas L=4 requires
X<=8. For L=3 the lambda count already fails.

If D=A3, zero leaves A1 D R P. A1 is a vacuous chain over c or s.
A c chain cannot produce head R. A positive-length chain over s erases D
on its first argument, losing j. Only literal A1=s remains, giving
P D R P -> D K R R P. D has at most L-1<=3 lambdas. If a receives K,
its distinguished application is consumed. If it receives either R,
the final P is still pending. It cannot receive the fourth input P.
Again final R j is impossible.

### Two body arguments

The two branch laws are

    A1[K/b,P/s] R P =beta R j,
    A2[F/b,S/s] V S =beta c V N.

The two branches together have four leaves. Zero requires a j in A1;
variable correctness requires a c in A2. If A1 has only one leaf it is a
vacuous chain over j, which cannot give zero head R. If A2 has only one
leaf it is a vacuous chain over c: applying V,S yields c V S, c S, c,
or a remaining abstraction, never c V N. Thus both branches have exactly
two leaves and one inner application.

If A1 has no live inner binder, its only source application cannot become
R j. Its function variable is b=K, s=P, or a rigid ambient variable; a
K/P function consumes that constructor, and a rigid source head is wrong.
Any surrounding inner lambdas are vacuous. The remaining external edges
have right arguments R,P, and the data edges have right K,R, none j.
This excludes every allocation except A1 containing the sole inner bound
leaf a as well as j. In that allocation A2 has exactly c,s and only vacuous
lambdas.

A beta-normal, one-application expression over c,s with only vacuous
lambdas is one of

    kappa^r (c (kappa^t s)),
    kappa^r (s (kappa^t c)),

where kappa^r is r vacuous lambdas. The first form, after V,S are applied,
has either the wrong number of c arguments or first argument kappa^t S;
that argument is not V. For the second form use

    S c -> c F V,
    S (kappa c) -> c V,
    S (kappa^t c) -> kappa^(t-2) c       (t>=2).

The outer r vacua discard an initial segment of V,S, after which the
remaining suffix is appended. Every resulting two-argument c spine is
c F V or c V S; other cases have another arity or remain abstractions.
For sufficiently large m neither is c V N. This excludes the last branch
allocation and completes the bound-head case.

## The repeated-stream affine five-lambda four-application allocation

This handwritten exclusion has been independently reviewed. Assume a
beta-normal nonleading whole-stream handler has

    A=4, L=5, X<=6, leaves s,s,j,c,v,

with v bound once and the other four source binders vacuous. We claim
this remaining L=5 allocation fails the variable law. Use the established
long-prefix guard and the requirement of three source contractions with
c in their function bodies, forced by the original F,V,S root edges.
The source is affine, so each source lambda contracts at most once.

### The live binder is a closed projection

The base ambient index contribution is three, leaving total source-lambda
tax at most three. The live binder's body cannot contain an ambient leaf.
If it did, that live lambda would have positive tax, and every vacuum
would also have positive tax. A vacuum containing the live binder would
also contain that ambient leaf; one not containing the live binder has
no live binder in its own nonempty body, so has a free leaf there. This
would give total tax at least five.

Thus the live lambda is a closed projection: its body has only its one
bound leaf, with some number h of vacuous lambdas between that binder and
the leaf. Each of these h inner vacua has tax one. Write r for the number
of source lambdas above the unique ambient c leaf. None is the live
binder, so all r are vacuous and each has tax at least one.

The two sets are disjoint. A source lambda can contain c at contraction
only if it initially lies above c, or if it is one of the h inner vacua
and the live binder has been supplied an argument containing c. There is
no other live binder through which c could enter a body. A vacuum above
the whole live block activates before that block and cannot acquire c
later through its substitution.

Consequently the three required contractions imply r+h>=3, while the tax
budget gives r+h<=3. Equality holds:

    r+h=3,

all these lambdas have tax exactly one, and every other lambda has tax
zero. In particular neither j nor either s can lie under any source
lambda. No one of the r+h potentially c-containing constructors can be
spent in an internal contraction: all three are needed at the three
original external root applications.

### A captured c cannot supply the missing constructors

The source-normal block containing c is a consecutive vacuous chain

    C=lambda^r.c B1 ... Bt.

Every Bi is closed: j and s are forbidden below these lambdas, c is
unique, and there is no surrounding live binder. A normal application
outside that c head cannot be headed by a closed lambda block, since
that would be a source redex. This also shows that the r c-ancestor
lambdas are consecutive; without another ambient head, a normal body
that still contains c beneath a further lambda must begin with that
lambda.

Any closed source block appearing among the Bi is permanently guarded
by rigid c. It cannot be extracted to receive an argument containing c.
Thus if the live binder ever receives c, its projection block must lie
outside this c-headed block.

In that case every source lambda is either one of the r lambdas in C,
one of the h inner vacua of the live projection, the live binder itself,
or a closed vacuous prefix immediately above the live binder. A zero-tax
vacuum must enclose the sole live binder, and its closed one-leaf body
forces this consecutive prefix. Since L=5 and r+h=3, there is exactly
one such prefix vacuum. The complete closed projection is therefore

    D=lambda w v.lambda^h.v.

Before a source activation, the exterior basis consists only of the two
copies of S and rigid markers. It cannot return a source block bare; a
first activation can be chosen at a literal s callback. The callback
cannot be C, because that would spend one of the three c-containing
constructors internally. It must be D. Its Scott invocation supplies F
to w and V=P_(m-1) to v. The only live binder therefore receives data
without c, contradicting this case. This rules out c entering any of the
h inner vacua through capture.

The same argument covers r=0: the c-headed normal source expression is
rigid, and the only lambda block that can be activated is D.

### The three constructors must already enclose c

Since capture is impossible, all three required constructors must be
above c initially. Thus r=3 and h=0. The only other two source lambdas
form the closed block

    F=lambda w v.v.

If this F block lies inside C, all source lambdas lie in C and the first
source activation spends a c-containing constructor internally, which
is impossible. Otherwise F is outside C and C=lambda^3.c: its body
cannot contain j or s, and the only remaining bound leaf belongs to the
disjoint F block.

The first successful source activation must therefore be the literal
s F; it returns V and consumes both source lambdas of F. Only the intact
constant chain C remains. Internally activating it would again spend a
constructor needed at an external root. A bare C given the three external
arguments returns bare c, not c V N. Safe functional data has no c, and
an ordinary rigid head retains the final input S. These alternatives
exhaust the outer normalization and all fail.

The repeated-stream affine A4,L5 allocation is therefore excluded.

## Four lambdas with two stream leaves and one affine live binder

Suppose H is beta-normal, nonleading and affine, with A=4,
L=4, X<=8, and leaf allocation

    s,s,j,c,u,

where u is the sole bound-variable occurrence. We exclude the variable
law using the source-constructor accounting from the affine tax proof.

Choose a sufficiently long variable stream S=P_m and V=P_(m-1), so the
affine safe-data guard excludes c-carrying data lambdas. The three original
external application constructors carrying F,V,S must each contract with
a source lambda whose body contains the unique c. Thus three distinct
source lambda constructors are consumed by those original external edges.

Because H is source-normal and application-headed, exposing any source
lambda at the global head requires an internal source activation. The
first such activation can be chosen at a literal source subterm s D;
its first source contraction supplies F to the first binder of D. There
are only four source lambda constructors and no copying. Consequently
this is the only source-lambda contraction that is not one of the three
original external contractions. In particular there is no later internal
source activation, even during normalization of output arguments.

All four source contractions therefore have c-free arguments: the first
has F, and the other three have the unchanged original data F,V,S. No
source substitution can move c into a source lambda that did not already
contain c. The safe data cannot do so either. Each of the three source
lambda constructors used by the original external edges must therefore
be an original ancestor of c in H.

Let Z be the innermost of these three ancestors. It is in fact the
innermost source lambda above c: the fourth lambda cannot lie inside Z
and be the first activation, because the opaque-block strategy does not
activate a source binder below an intact outer source binder. Its source
body B contains no further source lambda. Any additional lambda in B
would have to be the fourth one, which again could not have been the
first internal activation before Z was reached. All the other three
lambda constructors are ancestors of c, so none can lie in a side branch
of B.

The source depth of c is at least three. The ambient base of j,c is
three, leaving at most five source-crossing units because X<=8. If either
s or j occurred in B, it too would lie beneath the same three original
source ancestors and contribute three further crossings. Along with the
three crossings already charged by c this would exceed the allowance
five. Thus B has no s or j. Its only possible leaves are c and the
single bound occurrence u, and it has no source lambda. It is therefore
one of

    c,       c u,       u c.

The first internal activation may have been an ancestor of Z or may have
occurred in a separate helper; this does not affect the conclusion. Any
u occurrence in B is supplied with one of F,V,S, since these are exactly
the source-contraction arguments. The three c-bearing ancestor lambdas
are consumed by the original external edges in their nesting order, so
Z is the lambda contracted by the final original S edge. That edge is
the outermost application of the complete invocation. After it contracts,
the entire result is B with the already determined safe value U substituted
for u. No old source application remains outside this body.

If B=c or c u, the result has respectively zero or one argument to c,
not the required two. If B=u c, then

    F c = I,
    V c = c F P_(m-2),
    S c = c F V.

For sufficiently large m none is c V N: the Scott cases have first
argument F instead of V. This contradiction excludes the allocation.

## Four applications, one leading lambda, and a stream-headed three-lambda body

Suppose a beta-normal whole-stream handler has four applications, three
source lambdas, exactly one leading lambda, and normal body head `s`:

```
H = λb.B,             B = s A₁ ... A_q,             q≥1.
```

There are five variable leaves and two source lambdas inside `B`. Mandatory
`j,c,s` occupy at least three leaves. We exclude the variable law; the wire
budget and the zero law are not needed in this last shape argument.

Choose a sufficiently long variable stream `S=P_m`, with `V=P_(m-1)`.
The invocation first contracts the leading binder against `F`, leaving
`B[F/b] V S`. We use the established opaque-source normalization strategy
and safe-data ancestry guard. In particular no data lambda can capture a
surviving `c`, and a first source activation in a normal expression with
exterior basis only `S` and rigid variables is at a literal source `s D`,
supplying `F` to the first binder of `D`.

### The leading binder is used

If `b` is absent, before the first inner source activation the exterior
algebra contains only `S`, `Q`, rigid neutrals, and opaque source blocks.
It cannot return a source block bare: applying `S` to that block activates
it, and `Q` erases its argument. If no inner source activation occurs, the
ordinary data-algebra obstruction applies.

At the first activation `s D`, the first source binder receives `F`.
Even if that binder is nonlinear, copying `F` copies no source lambda.
At most one source lambda then remains, with both original external inputs
`V,S` still pending. The extended one-source-lambda obstruction excludes
this result. Thus a successful candidate must contain a `b` leaf.

Once `b` occurs, the five-leaf budget allows at most one occurrence bound
by either inner source lambda: `s,j,c,b` already occupy four leaves.
Both inner source lambdas are therefore affine after substituting `F`
for `b`; a second `b` copies only the safe data `F`.

### Both inner lambdas must surround the eventual c

Tag the original external applications carrying `V,S`. To obtain
`c V N`, the final `S` application must contract, since otherwise its
unchanged right argument would be the final `S`, not `N`. Its function
can become a lambda only after the original `V` application contracts.
Each of these two contractions has a surviving `c` in the function
lambda's body: the original right arguments contain no `c`.

Safe data cannot supply such a lambda. There are exactly two affine
source lambdas left, so both are consumed by these two tagged applications.
There is no inner source activation before them or elsewhere in the
required normalization. Their only earlier source substitution was
`b:=F`, which is `c`-free. Consequently both source lambda constructors
were original ancestors of a single occurrence of `c` that survives to
the result. They lie in one outermost source block `D`.

Before the original `V` edge contracts, exterior normalization must
therefore return this `D` bare, without activating either source lambda.
There must be an occurrence of `b` outside `D`. Otherwise the exterior
basis is only `S` and rigid variables; as above that algebra cannot return
an opaque source block bare without activating it. The source head `s`
also lies outside `D`. Hence `D` has at most three variable leaves.

If `D` has three leaves, the exterior has exactly the three macro leaves
`s,b,D`. Since its head is `s`, its four possible application trees are

```
s b D,          s D b,          s (b D),          s (D b).
```

The last is not source-normal. After `b:=F`, the second activates `D`
internally. The first reduces to `V D`, which also activates `D`
internally for `m≥2`. The third reduces to `S I = I` and erases `D`.
Each contradicts the required bare return of `D`. Thus `D` has at most
two variable leaves.

### The remaining block grammar fails directly

If `D` has only one leaf, both lambdas surround that `c`, so
`D=λu v.c` and `D V S=c`, of the wrong arity.

If `D` has two leaves, write the second one as `e`. Both lambdas surround
`c`, `D` is normal, and there is only one application inside it. Its full
grammar is therefore

```
D = λu v.c e,          D = λu v.e c,          D = λu.e (λv.c).
```

In the first two forms, after the inputs `V,S` and the earlier substitution
`b:=F`, the leaf `e` becomes one of `F,V,S` or a rigid ambient variable.
The first form gives `c e`, with only one argument. In the second,

```
F c = I,             V c = c F P_(m-2),             S c = c F V.
```

A rigid `e` has the wrong head, or gives the one-argument `c c`.
The Scott cases have first argument `F`, whereas the target's first
argument is `V`; these are distinct for large `m`.

In the last form, `v` is vacuous and `e` cannot refer to it. Write
`K_c=λv.c`. The full result is `e K_c S`, with `e` again one of
`F,V,S` or a rigid ambient variable. The three data cases are

```
F K_c S = S,         V K_c S = c P_(m-2) S,         S K_c S = c V S.
```

A rigid `e` either has the wrong head or produces `c K_c S`.
Every `c`-headed result retains final `S`, not `N`.

Thus no beta-normal `A=4,L=3` handler with exactly one leading lambda and
stream-headed body satisfies the whole-stream reader laws.

## Four applications and four lambdas, with a leading stream-headed body

Let H=lambda b.B be source-beta-normal, with exactly one
leading lambda, A=4,L=4,X<=8, and normal body head s. Its five leaves are
j,c,s and two additional leaves. On a variable input, first substitute
b=F. The residual has three source lambdas, and the original final inputs
V=P_(m-1),S=P_m are still pending.

### Which inner lambdas can carry c

The mandatory j,c,s under the outer binder contribute 2+3+1=6 to X.
At most two inner crossing units remain. For affine residual code, each
of the two final original application edges must consume a source lambda
whose body contains c, by the guarded c-ancestry argument. The relevant
crossings are the inner ancestors of c and crossings of an occurrence
bound by an inner live binder. Crossings of j,s, or b cannot supply c:
j stays rigid, s is initially safe c-free data, and b has become safe F.
Source lambdas containing only those fixed outside references are closed
with respect to c transport until an inner live binder supplies c through
one of its crossed occurrences. Count each such possibly c-carrying
lambda once; its existence costs one of the relevant crossing units.

Consequently the affine cases require at least two relevant inner crossing
units. Since there are at most two units altogether, equality holds:
j,s,b are outside all inner lambdas, no extra ambient occurrence is
possible, and the two relevant units are the entire inner tax. In
particular a repeated ambient s costs its outer crossing, while a repeated
j costs even more, leaving fewer than two relevant units and failing.

The only nonlinear residual possibility has both spare leaves bound by
one inner binder u. Then b is vacuous and s is unique. The ordered-input
one-live proof applies with the shortened zero list

    K,R,A2,...,Aq,R,P,

of length q+3>=4. A K value leaves selectors and vacuous erasers; a common
argument has a fixed rigid head; and an R or final P value requires the
leading callback chain to consume the entire list. Thus at least four
inner source lambdas would be necessary. There are only three. This
excludes the nonlinear residual without using the affine argument.

If both spare leaves are b, the residual has no inner live binder. Two
c-carrying inner lambdas require c below two of them and spend both units.
The third inner lambda must also have a leaf in its body, but there is no
inner bound leaf available and no other ambient crossing unit. It cannot
be placed. Thus this case is impossible as well.

### The outer binder is vacuous

The remaining affine allocation without b is j,c,s,u,v, with two distinct
inner live binders. The exterior initial data basis is just S and rigid
markers. Its first source activation must therefore occur internally at
a literal s D and supplies F, as in the normal lambda-floor proof.

There are exactly three inner source lambdas: this one internal activation
and the two original external contractions using V,S exhaust them. All
three arguments are c-free. Hence the two source lambdas used by the
external edges were already ancestors of c. Their two crossings spend
the complete inner tax; no other source crossing is possible.

The first internally activated lambda is not an ancestor of c, since
that would require a third crossing. It is a separate one-lambda block,
with one bound leaf, necessarily I. The two remaining source lambdas form
the c block. If they are consecutive, the outer one is vacuous: a reference
to its binder below the inner lambda would spend an additional unit. The
other live occurrence is then bound by the innermost lambda, whose body is
c v or v c. After the final original S edge contracts these give c S or
S c=c F V, neither c V N.

If the two c ancestors are not consecutive, their only normal arrangement
with leaves c,v is lambda v. v (lambda a.c). Its outer lambda receives
the first external V, after which V (lambda a.c) invokes the inner source
lambda internally with F. That leaves no source lambda for the final
original S edge, contradicting the required two external contractions.
These cases exhaust the c block and exclude the vacuous-outer case.

### One outer occurrence b and one inner occurrence u

Now the leaves are j,c,s,b,u. The inner binder U is affine. Equality above
puts j,s,b outside all three inner lambdas. Their entire source syntax
therefore involves only c and u. Write

    C_r=lambda^r.c,          D_p=lambda u.lambda^(p-1).u.

A chain of zero lambdas is allowed for C_0=c. There are only two possible
arrangements of the two leaves and three lambdas.

If they lie in separate chains, let r be the number around c and p the
number around u. Then r+p=3. If u is bound at position i in its chain,
the relevant tax is r+(p-i)=3-i=2, so i=1. Thus the chains are exactly
C_r,D_p with r=0,1,2 and p=3-r.

If they are joined by their one source application, beta-normality makes
the function leaf c or u. A u-headed application requires the u binder
to enclose the c branch; the three lambdas then contribute at least three
relevant crossing units, impossible. In a c-headed application, u cannot
be bound in a common prefix, for the same reason. Thus the expression is

    lambda^r. c D_p,       r+p=3, p>=1.

The closed D_p is trapped as an argument of rigid c and cannot acquire c.
Only the r outer vacuous lambdas can carry c. Therefore r must be at least
two, forcing r=2,p=1. This block yields c I after the two original external
contractions, rather than c V N.

It remains to handle the separate chains C_r,D_p. If r=2,p=1, C_2 must
supply both c-carrying external contractions. It has body c, so the final
result after the S edge is c. Any earlier activation of C_2 would leave
fewer than two c-carrying lambdas for the external edges.

Suppose r<=1, so p>=2. The two c-carrying lambda constructors must be all
r lambdas of C_r and all p-1 inner vacuous lambdas of D_p. Consequently
C_r cannot activate internally, and D_p's outer U must be activated
internally with an argument containing c. Supplying it F or any other
c-free value leaves its entire residual chain c-free and cannot work.

Before this U activation, treat D_p and C_r as markers d,z (with z=c for
r=0). No source lambda has yet activated. The body is an application tree
of exactly four applications over the five single-occurrence atoms

    s,b,j,d,z,

with head s. Source normality forbids d, and z when r>0, in source function
position. After b=F, a direct callback d would receive F and fail the
c-carrying requirement. A callback z either spends a forbidden internal
c-carrying contraction or is rigid c. A j-headed callback stays rigid.

A bare callback b gives S F=V; with b now gone, its next callback can only
be d,z, or a rigid-headed expression, so has the same failure. The only
way to expose d without first supplying it the Scott bit F is to make the
first callback I. With the single b occurrence this requires b X. Its
erased argument X must be j: erasing either d or z loses a required block.
A callback b X Y instead forwards Y, returning to the already excluded
callback cases. If a third argument is already inside the callback, the
only c-preserving possibility within four applications is

    B = s (b j D_p C_r).

Here D_p C_r produces lambda^2.c, which the surrounding S immediately
invokes internally. This spends c-carrying lambdas before the two external
edges and fails. The reversed arrangement s (b j C_r D_p) likewise activates
C_r internally, or exposes rigid c when r=0. These alternatives also cover nested application operands,
since an erased operand containing d or z loses that unique block.

Thus the only viable four-application arrangement is

    B = s (b j) D_p C_r.

The reverse order exposes C_r internally or rigid c and fails. On the
variable input the displayed arrangement reduces to

    S (F j) D_p C_r =beta D_p C_r
                      =beta lambda^(p-1).C_r.

Since (p-1)+r=2, applying V,S gives bare c. It cannot give c V N.

All leaf allocations are exhausted. Hence no normal A=4,L=4,k=1 handler
with body head s and X<=8 satisfies both whole-stream laws.

## Established bounds and remaining scope

Combining the compression lemmas, the beta-normal lambda floors, and the
complete shape arguments proves:

> In the ambient frame `[s,j,c,p,x]`, with `j,c,p,x` independent
> and rigid, every handler satisfying both whole-stream reader laws has
> `|H|≥35` for `T=s`, or `|H|≥31` for `T=s s`. This includes handlers
> with arbitrary source beta redexes and arbitrary use of `s`.

The reduction to normal shapes does not assume that every small source
term normalizes. Affine contractions either preserve the improving budget
or have the separately excluded growing shape; every remaining nonlinear
source-redex allocation is excluded. A minimum successful candidate would
therefore be beta-normal. The normal cases with at most three applications
fail; the five-application cases fail by the two-source binary/affine and
continuation-ancestry arguments; and the four-application cases are exhausted
by leading-lambda count, stream multiplicity, and bound-leaf allocation.

The size identity for the reader is `|s H T|=6+|H|+|T|` in the stated
frame. The two bounds give `6+35+2=43` and `6+31+6=43`. The standard-skip
bound in `handler-bound.md` gives `6+27+10=43`, attained by the existing
reader. Thus **43 bits is the minimum across these three operand families**.
With the other 122 bits fixed, **165 is minimal within these three operand
families under the stated independent rigid reader laws**.

The independent rigid continuation assumptions and the specified reader
interface have not been removed. Bare operands `j,c`, operands containing
lambdas, other reader heads, exploitation of the actual NEXT/parser
behavior, and arbitrary complete interpreters remain outside this theorem.
This is not a global optimality theorem for the 165-bit interpreter.
Neutral-operand domination and the application-only operand classification
are in `protocol-obstructions.md`.
