Setting. Contract: E C (<M> ++ N) =b C (\z. M) N for every closed M, C and N rigid free variables. Streams cons b r = \f. f b r, bit0 K, bit1 F. Canonical values (the 162's): Abs(f) = \e a. f (cell a e); App(f,g) = \e. f e (g e); variable value = raw remaining unary code r; cell a e = \zx zy. zx a (zy e). The 162 parses CPS: parser P c s; on a variable the reader returns c r N; constructor returns are eta-forwarded, e.g. ABS returns `cont (Abs exp)` so the rest passes verbatim.

Let W = (\w. w w)(\w. w w), v_W = the canonical value of `\y. W`. Fact: v_W A1 is a lambda, and v_W A1 A2 A3.. =b W A3.. (unsolvable) for every A1, A2 (f_W E = g E (g E), g E =b \a. a a since variable 1's raw code selects the cell's head).

Lemma A. Let kappa be a term whose only free variable is C, with kappa v_W N =b C X N for some X. Then kappa x y ->b C A y for fresh x, y and some A.
Proof. kappa x y is solvable (substitution instances of unsolvable terms are unsolvable). Its hnf has no leading lambda (instance's would remain). Head x: instance =b v_W A1'..Am': a lambda for m <= 1, unsolvable for m >= 2; never =b C X N. Head y: N-headed hnf, distinct head from C. So head C with exactly two args and A2[v_W/x, N/y] =b N. Same split on A2[x,y]: leading lambda, head x, head C, head y with >= 1 arg all give instances not =b N; so A2[x,y] ->b y.

Corollary. Hypotheses: (H1) on the program \x.\y.W the root lambda's body continuation kappa_C is handed (a term =b v_W, N) and that call's result is the run's result; (H2) kappa_C is fixed before the body's code is read, so the same kappa_C is the body continuation for \x.x; (H3) on \x.x the run's result T can be written T'[kappa_C/kappa] with T' free of C (C enters only through the continuation; true when the parser is closed). Then T' ->h kappa X Y with exactly two arguments and Y ->b N with kappa free (case split on Y's hnf: kappa-headed instances are C-headed, or kappa_C B1 which cannot be =b N since kappa_C B1 z =b C A z; N with args or lambda-headed are not N). Consequences claimed: (i) a reader returning `c r j` (j = NEXT, N-free) on variables fails for EVERY choice of NEXT continuation code, not only for rigid c; (ii) a variable arm returning `c X N Z` (trailing junk) fails for every continuation; (iii) the separated class's rigid variable law R U_n(N) = c U_(n-1)(N) N is forced in its rest component for every interpreter satisfying H1-H3; only the value component (X acting as r on environments) is relaxed.
